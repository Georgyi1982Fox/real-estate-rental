# Bina.ai — FRONTEND-001

Базовый frontend scaffold для Telegram Mini App аренды недвижимости.

## Структура

- `templates/base.html` — общий layout и подключение стека.
- `templates/components/` — переиспользуемые UI-компоненты.
- `templates/pages/` — страницы приложения.
- `static/css/theme.css` — CSS-переменные дизайн-системы и Telegram theme mapping.
- `static/css/main.css` — глобальные responsive/a11y стили.
- `static/js/telegram.js` — Telegram Web App initialization.
- `static/js/app.js` — Alpine initialization.
- `static/js/utils.js` — безопасные frontend utilities.
- `mock_data.json` — стартовые mock-данные.
