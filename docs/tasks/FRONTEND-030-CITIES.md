# FRONTEND-030: Выбор города (вся Грузия)

## Контекст (бэкенд TASK-079)
- `GET /api/cities` (без входа) → `items[{code, name{ka,ru,en}, latitude, longitude}]` —
  **только города, где уже есть объявления**. Сейчас их 15: tbilisi, batumi, kutaisi,
  rustavi, zugdidi, gori, poti, telavi, mtskheta, kobuleti, borjomi, bakuriani, tskaltubo,
  akhaltsikhe, gonio. Всего сервис знает 26 городов, список растёт сам — не зашивать его в код.
- `GET /api/districts?city=batumi`: районы города; у района есть поле `city`.
- `GET /api/listings?city=batumi`: объявления города (вместе с остальными фильтрами).
- Сохранённый поиск: `filters.city` (`POST/PUT /api/searches`).
- Подробности — `docs/tasks/TASK-079-CITIES.md`.

## Что сделать
1. **Выбор города** над поиском на странице `/search` (и на главной над строкой поиска) из `GET /api/cities`: городов может быть больше десяти —
   кнопка «📍 Тбилиси ▾» и список (с поиском по названию, если городов больше 8).
   Выбор запомнить (localStorage), по умолчанию — Тбилиси. Пункт «Вся Грузия» — без `city`.
2. **Фильтр районов** загружает районы только выбранного города
   (`/api/districts?city=…`). При смене города выбранные районы сбрасываются.
3. **Список объявлений** запрашивается с `city=…`.
4. **Сохранение поиска** передаёт `city` в фильтрах.
5. **Карта** по умолчанию центрируется на центре выбранного города.
6. Все тексты ka / ru / en.

## Проверка
- Переключить на Батуми → районы и объявления только Батуми; назад на Тбилиси — тбилисские.
- В списке городов нет пустых (без объявлений).
- Подсказки районов в строке поиска (FRONTEND-014) — только районы выбранного города
  (сейчас подсказки идут из всех городов сразу).
- `npx tsc --noEmit` и `npm run build` без ошибок.
