# TASK-105: Сравнение квартир

## Что умеет
`GET /api/listings/compare?ids=<id1>,<id2>,<id3>` (или `ids=…&ids=…`) — 2-3 квартиры в одной
таблице. Доступно всем. Суммы в лари, подписи строк и пояснение — на языке пользователя.

| Строка (`rows[].code`) | Что это | Лучше |
|---|---|---|
| `price` | Аренда в месяц | меньше |
| `price_per_m2` | Цена за м² | меньше |
| `area`, `rooms`, `floor` | Площадь, комнаты, этаж | больше площадь |
| `district`, `minutes_to_center`, `metro` | Район, минут до центра на машине, метро (TASK-104) | меньше минут |
| `move_in` | Отдать при въезде: аренда + залог за месяц + коммунальные (TASK-103) | меньше |
| `average_month` | В среднем в месяц с коммунальными (2 человека) | меньше |
| `price_level` | Оценка цены: `below` / `fair` / `above` / `unknown` (TASK-093) | — |
| `risk_level` | Риск: `none` / `warning` / `high` (TASK-094) | меньше |
| `features` | Коды удобств | больше |

`best` — для каждой строки ID квартир с лучшим значением (при равенстве — все).
Строка не отмечается, если значение известно меньше чем у двух квартир или у всех одинаковое.

Ошибки: 422 — меньше 2 или больше 3 разных ID, неизвестная валюта; 404 — объявления нет.

## Код
`application/compare.py` (строки, подписи, выбор лучшего),
`infrastructure/api/routes/compare.py` (подключён до `listings`, чтобы `compare` не принимался за ID).
