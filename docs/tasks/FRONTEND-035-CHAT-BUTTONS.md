# FRONTEND-035: «Написать хозяину» и «Записаться на просмотр» на сайте

## Контекст (бэкенд TASK-111, TASK-112)
Переписка с хозяином и запись на просмотр работают в боте: бот переводит сообщения
на язык собеседника. Подробности — `docs/tasks/TASK-111-CHAT-VIEWINGS.md`.
На сайте нужны кнопки, которые открывают это в боте.

## Что сделать
1. На странице объявления и в карточке списка — только если `source === "owner"`
   (объявление разместил сам хозяин): две кнопки
   **«💬 Написать хозяину»** и **«📅 Записаться на просмотр»**.
2. Обе ведут в бота: `https://t.me/<бот>?start=chat_<id объявления>` — бот откроет
   карточку квартиры с этими же кнопками.
   В Mini App — `Telegram.WebApp.openTelegramLink(...)`, на обычном сайте — новая вкладка
   (компонент `OpenInTelegram`).
3. Под кнопками маленькая подпись: «Бот переведёт ваше сообщение на язык хозяина».
4. Тексты ka / ru / en.

## Проверка
- У объявления с сайтов (ss, myhome, …) кнопок нет, у объявления хозяина — есть.
- Нажатие открывает бота на карточке этой квартиры.
- `npx tsc --noEmit` и `npm run build` без ошибок.
