# Временная страница «🧪 Проверка функций» (для владельца)

Чтобы владелец видел и пробовал новые функции бэкенда, пока у них нет экранов
(FRONTEND-023…029). Без дизайна, **удалить**, когда появятся нормальные экраны.

## Как открыть
В боте → «🏠 Главное меню» → **«🧪 Проверка функций»** (кнопка видна только Telegram ID из
`ADMIN_TELEGRAM_IDS` и только если задан `BOT_MINI_APP_URL`). Откроется Mini App на `/lab`.
Другим пользователям страница пишет «только для владельца» (`/api/me` → `is_admin`).

## Что на странице
Выбор объявления, затем кнопки:
- 💰 калькулятор стоимости (въезд, средний месяц, 12 месяцев, коммунальные по месяцам);
- 📍 информация о районе (время до центра, метро, описание, обычные цены);
- 🗺 место на карте (точно / примерно, ссылки на Google, Яндекс, OpenStreetMap);
- ⚖️ сравнение 2–3 объявлений (лучшее в строке отмечено);
- 📄 договор аренды и ✅ акт приёмки — PDF приходит в чат с ботом;
- ⚠️ жалоба на объявление;
- 🎁 ссылка «пригласить друга».

Тексты — ka / ru / en по языку интерфейса.

## Код
`frontend/src/pages/FeatureLabPage.tsx` (свой словарь, не трогает общий), маршрут `/lab` в
`App.tsx`; бэкенд: `ADMIN_TELEGRAM_IDS` в `ApiSettings`, `is_admin` в `/api/me`, кнопка в
`bot/keyboards/menu.py`.

## Удалить потом
Файл страницы, маршрут `/lab`, ключ `menu_lab` и кнопку в меню бота.
