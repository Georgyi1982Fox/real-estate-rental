# FRONTEND-047: Гостиницы — «🔥 Топ» за звёзды, «Поделиться» и «Написать хозяину»

**Бэкенд готов** (TASK-120, этап 2). Продолжение FRONTEND-045: значок «🔥 Топ» в списке
и на странице гостиницы уже есть (`is_promoted`), теперь хозяин может сам купить «Топ»,
а любой — поделиться гостиницей ссылкой на бота или написать хозяину через бота
(с автопереводом).

## Контекст (бэкенд)
- `GET /api/hotels/options` — новые поля `promotion_price_stars` (сейчас 150) и
  `promotion_days` (7).
- `GET /api/my/hotels` и `GET /api/my/hotels/{id}` — новое поле `promoted_until`
  (дата-время или `null`; если в прошлом — «Топ» уже закончился).
- `POST /api/my/hotels/{id}/promotion` (нужен вход) → `{url, price_stars, days}`:
  ссылка на счёт в звёздах для `Telegram.WebApp.openInvoice`. Ошибки:
  - 404 — не свой объект;
  - 409 — объект не в разделе (снят с показа, скрыт или нет ни одного номера с ценой);
  - 503 — оплата на сервере не настроена.
- Оплату принимает бот: после `openInvoice` со статусом `paid` бот сам поднимает объект
  в «Топ» и присылает хозяину сообщение. Повторная оплата продлевает срок ещё на 7 дней.
- `GET /api/hotels/{id}/share?lang=ka|ru|en` (вход не нужен) → `{url, text, telegram_url}`:
  `url` — карточка гостиницы в боте (`https://t.me/<бот>?start=h_<id>`), `text` — подпись
  «Название · от 120 ₾», `telegram_url` — окно Telegram «Переслать». 404 — объекта нет
  в разделе, 503 — бот не настроен (кнопки не показывать). Как `GET /api/listings/{id}/share`
  у квартир (FRONTEND-041).
- В карточке бота есть «✍️ Написать хозяину»: гость пишет на своём языке, бот переводит
  хозяину и пересылает ответ обратно. Telegram друг друга не видно.

## Что сделать
1. **«Мои гостиницы»** (`MyHotelsPage`), у каждого включённого объекта (`status: active`)
   с ценой — кнопка «🔥 Топ на 7 дней · 150 ⭐» (цифры — из `options`).
   - Нажатие → `POST /api/my/hotels/{id}/promotion` → `openInvoice(url)` (как покупка
     Premium в `useSubscription.ts`).
   - `paid` → сообщение «🔥 Готово! Объект в топе до …» и перезагрузить список
     (через пару секунд: оплату записывает бот). `cancelled` — ничего не делать,
     `failed` — сообщение об ошибке.
   - Ответ 409 → подсказка «Включите объект и добавьте номер с ценой».
2. **Срок «Топ».** Если `promoted_until` в будущем — под объектом «🔥 В топе до 26.10»,
   а кнопка — «🔥 Продлить топ · 150 ⭐».
3. **«📤 Поделиться»** на странице гостиницы (`HotelPage`): `telegram_url` из
   `GET /api/hotels/{id}/share` (как у квартир, FRONTEND-041); в браузере — копирование `url`.
4. **«💬 Написать хозяину в боте»** на странице гостиницы рядом с «Позвонить» / WhatsApp:
   открыть `url` из того же ответа (`Telegram.WebApp.openTelegramLink`, в браузере — новая
   вкладка). Подсказка под кнопкой: «Бот переведёт сообщение на язык хозяина». У своей
   гостиницы кнопку не показывать.
5. Тексты на трёх языках (ka / ru / en).

## Проверка
- «Мои гостиницы» → «🔥 Топ» → окно оплаты Telegram со звёздами → после оплаты объект
  первым в разделе «Гостиницы» со значком, в «Мои гостиницы» — «В топе до …».
- Снять объект с показа → «🔥 Топ» не показывается (или подсказка при нажатии).
- «📤 Поделиться» → отправить ссылку себе → нажать → бот показывает карточку гостиницы.
- «💬 Написать хозяину в боте» → открывается бот с карточкой → «✍️ Написать хозяину» →
  написать по-русски → хозяину (с грузинским языком в боте) приходит перевод на грузинский.
- Переключить язык → все новые надписи на новом языке.
- `npx tsc --noEmit` и `npm run build` без ошибок.
