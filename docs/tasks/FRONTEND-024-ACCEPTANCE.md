# FRONTEND-024: «Акт приёмки квартиры» (Premium)

## Контекст (бэкенд TASK-102)
- `GET /api/documents/acceptance/checklist` → разделы, пункты и состояния **уже на языке
  пользователя** — тексты пунктов в приложении не хранить.
- `POST /api/documents/acceptance` → бот присылает PDF в чат. Поля — в `TASK-102-ACCEPTANCE.md`.
- 402 без Premium, 422 ошибки в полях, 502 бот не смог отправить.

## Что сделать
1. Кнопка **«Акт приёмки»**: в объявлении (передать `listing_id`) и в профиле (без объявления,
   тогда адрес вводится вручную).
2. Экран-чек-лист по разделам. У каждого пункта три кнопки состояния
   («В порядке» / «Дефект» / «Отсутствует») и поле комментария (появляется при «Дефект»).
   Кнопка «Всё в порядке» для раздела. Пункты без отметки не отправлять.
3. Внизу: имена хозяина и арендатора, дата (сегодня), ключи, счётчики (свет, газ, вода),
   примечания, второй язык (ru / en).
4. Черновик сохранять в `localStorage`, чтобы не потерять при закрытии.
5. «Получить акт» → `delivery: "chat"`; успех — «Акт отправлен в чат с ботом».
6. 402 — окно Premium; 422 — подсветить поля; 502 — «Запустите бота (/start)».
7. Все тексты ka / ru / en.

## Проверка
- С Premium акт приходит в чат; при английском интерфейсе всё на английском.
- `npx tsc --noEmit` и `npm run build` без ошибок.
