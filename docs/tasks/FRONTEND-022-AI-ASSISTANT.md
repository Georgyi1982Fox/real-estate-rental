# FRONTEND-022: AI-помощник в объявлении (Premium)

## Контекст (бэкенд TASK-095)
- `POST /api/listings/{id}/assistant` `{"action": "message_owner" | "viewing_questions", "note": "…"}`
  → `{"text_ka", "translation", "questions", "remaining_today"}`.
- `GET /api/listings/{id}/cheaper` → `{"items": [Listing…]}` (как `/similar`).
- Без Premium — 402 (`payment_required`), лимит на день исчерпан — 429, AI не ответил — 502.

## Что сделать
1. На странице объявления блок «AI-помощник» с тремя кнопками:
   - **«Написать хозяину»** — поле «О себе (необязательно)», кнопка «Составить». Показать
     грузинский текст и перевод, кнопки «Скопировать» и «Открыть объявление»
     (пользователь отправляет сам — мы сообщения не отправляем).
   - **«Что спросить на просмотре»** — список вопросов с галочками.
   - **«Похожие дешевле»** — карточки как в «Похожих».
2. Загрузка: ответ AI идёт 5-20 секунд — показать индикатор и не давать нажать дважды.
3. 402 — окно «Подключить Premium» (как в FRONTEND-011); 429 — «Лимит на сегодня исчерпан»;
   502 — «Не получилось, попробуйте ещё раз». Показывать «осталось сегодня: N».
4. Тексты ka / ru / en.

## Проверка
- С Premium все три кнопки работают; без Premium — окно Premium.
- `npx tsc --noEmit` и `npm run build` без ошибок.
