# FRONTEND-036: Значки «🔥 Топ» и «✅ Проверенный собственник»

## Контекст (бэкенд TASK-097, TASK-098)
Хозяин может оплатить «🔥 Топ» (7 дней вверху поиска) и подтвердить, что он собственник
(значок ✅). Подробности — `docs/tasks/TASK-097-PROMOTION-VERIFICATION.md`.

## Что сделать
1. В карточке объявления и на его странице:
   - `is_promoted: true` → значок **«🔥 Топ»** (оранжевый, рядом с ценой) и лёгкая
     оранжевая рамка карточки;
   - `is_verified: true` → значок **«✅ Проверенный собственник»** (зелёный). На странице
     объявления — с подсказкой: «Bina.ai проверил документ о собственности».
2. Порядок ленты не менять — бэкенд уже ставит «Топ» наверх.
3. В «Моих объявлениях» (FRONTEND-033) у объявления в поиске — кнопки
   **«🔥 Поднять в топ»** и **«✅ Подтвердить собственность»**: обе открывают бота
   (`https://t.me/<бот>?start=owner` — раздел «Сдать квартиру»), оплата и документ — там.
4. Тексты ka / ru / en.

## Проверка
- Объявление с `is_promoted` и `is_verified` показывает оба значка; без них — ни одного.
- В тёмной теме значки читаются.
- `npx tsc --noEmit` и `npm run build` без ошибок.
