# FRONTEND-043: «Недавно смотрели» и заметки в избранном

**Бэкенд готов** (TASK-074, TASK-075).

## 1. «🕘 Недавно смотрели»
- `GET /api/history?limit=20` (нужен вход) → `items[] {listing, viewed_at}`.
- Где: на главной (хабе) — лента карточек «Вы смотрели»; и отдельная страница (из профиля)
  со всем списком и кнопкой «Очистить» (`DELETE /api/history`).
- Просмотр записывается сам, когда открывается страница квартиры (запрос с initData) —
  ничего дополнительно вызывать не нужно.

## 2. Заметка к квартире в избранном
- `GET /api/favorites/notes` → `{notes: {listing_id: text}}` — загрузить вместе с избранным.
- На карточке в «Избранном» и на странице квартиры (если она в избранном) — поле
  «📝 Заметка» (до 300 символов). Сохранять по `PUT /api/favorites/{id}/note`
  `{note: "..."}` (пустая строка — удалить). 404 — квартиры нет в избранном.
- Заметку видит только сам пользователь.

Тексты на трёх языках (ka/ru/en).

## 3. Счётчик просмотров «👁 123»
В ответе `GET /api/listings/{id}` есть `views` — сколько раз квартиру открывали на Bina.ai
(сайт, приложение, бот; уже вместе с текущим просмотром). Показать на странице квартиры
рядом с датой публикации: «👁 123 просмотра». В списках поиска поле пустое (`null`) —
там не показывать.
