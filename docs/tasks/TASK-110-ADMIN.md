# TASK-110: Минимальная админка (в боте)

## Как включить
1. Узнайте свой Telegram ID: напишите боту **@userinfobot** — он ответит числом.
2. В `.env` добавьте строку `ADMIN_TELEGRAM_IDS=<ваш ID>` (несколько — через запятую).
3. Перезапустите: `update-bina.bat` (или `docker compose up -d bot`).

Остальным пользователям `/admin` отвечает «Не понял» — команда для них как будто не существует.

## Что умеет `/admin`
**Статистика:**
- пользователей всего и новых за неделю;
- сколько сейчас с оплаченным Premium;
- звёзды: за 30 дней (и сколько оплат) и всего;
- объявлений в поиске по источникам (ss, myhome, telegram);
- сколько скрыто и сколько открытых жалоб;
- 5 районов с наибольшим числом объявлений.

**Жалобы** (кнопка «⚠️ Жалобы (N)»): до 5 объявлений с открытыми жалобами — сначала с
наибольшим числом. Для каждого: название, источник, сколько жалоб, причины с количеством,
комментарии, ссылка на объявление и кнопки:
- **🙈 Скрыть** — объявление пропадает из поиска, жалобы закрываются;
- **✅ Вернуть в поиск** — жалобы отклонены, объявление снова видно (если было скрыто
  автоматически после 3 жалоб).

## Код
`infrastructure/db/repositories/admin.py`, `bot/handlers/admin.py`, настройка
`ADMIN_TELEGRAM_IDS` (`bot/settings.py`). Доступ также у пользователей с ролью `admin`.
