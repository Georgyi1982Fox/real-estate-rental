# TASK-019: Вся информация объявления на языке приложения

## Что было не так
При переключении языка часть данных оставалась на языке сайта: имя хозяина (часто по-грузински),
адрес, названия районов (парсер сохранял район с одним названием на всех трёх языках),
удобства (приложение знало 8 из 18 кодов и показывало остальные как есть по-английски).

## Что сделано
Без AI, мгновенно и бесплатно (`src/bina/application/localization.py`):

| Что | Как | Пример |
|---|---|---|
| Имя хозяина | транслитерация; названия компаний ЗАГЛАВНЫМИ — как есть | ნინო → Нино / Nino; Davit → Давит / დავიტ |
| Адрес | тип улицы — словарём, название — транслитерацией (грузинское — в именительном падеже) | ცაგარელის ქუჩა 26 → ул. Цагарели 26 / Tsagareli St. 26 |
| Район | словарь 40+ районов Тбилиси, остальные — транслитерация | Сабуртало → საბურთალო / Saburtalo; «Старий Тбилиси» (опечатка SS) → тот же район |
| Удобства | названия в приложении по кодам, на трёх языках (`frontend/src/i18n/features.ts`) | furniture → ავეჯი / Мебель / Furniture |

Язык источника остаётся как на сайте. Описание и заголовок переводит AI (TASK-010), как и раньше.

- Миграция `district_names` исправляет районы, которые парсер уже создал с одинаковыми названиями.
- Новые районы сразу создаются с названиями на трёх языках.

## API
`GET /api/listings`, `/api/listings/{id}`:
```json
{
  "address": {"ka": "ცაგარელის ქუჩა 26", "ru": "ул. Цагарели 26", "en": "Tsagareli St. 26"},
  "owner": {"name": {"ka": "ნინო", "ru": "Нино", "en": "Nino"}},
  "owner_name": "ნინო"
}
```
`owner_name` (как на сайте) остаётся для совместимости. Приложение уже умеет показывать
`address` и `owner.name` на языке интерфейса.

## Ограничения
Транслитерация — не перевод: «დავით» получится «Давит», а не «Давид». Для имён и улиц этого
достаточно; при желании для частых имён можно добавить словарь.
