# FRONTEND-028: «Пожаловаться» в объявлении

## Контекст (бэкенд TASK-106)
- `GET /api/complaints/reasons` → `[{"code": "fraud", "title": "Мошенничество"}, …]` — уже на
  языке пользователя.
- `POST /api/listings/{id}/complaints` `{"reason": "fraud", "comment": "…"}` →
  `{"accepted": true, "message": "…"}`. 429 — лимит жалоб на сегодня.

## Что сделать
1. В меню «⋯» карточки объявления пункт **«Пожаловаться»** (мелко, не на виду).
2. Окно: список причин (радио-кнопки), поле «Подробнее (необязательно)», кнопка «Отправить».
3. Успех — показать `message`, окно закрыть; повторно на это объявление можно, но
   это обновит причину.
4. 429 — «Слишком много жалоб сегодня, попробуйте завтра».
5. Все тексты ka / ru / en.

## Проверка
- Жалоба отправляется, сообщение на языке интерфейса.
- `npx tsc --noEmit` и `npm run build` без ошибок.
