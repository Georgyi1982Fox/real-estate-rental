# FRONTEND-028: «Пожаловаться» на объявление

**Бэкенд готов** (TASK-106). Окно жалобы уже есть: `components/ComplaintModal.tsx`
(сделано для гостиниц в FRONTEND-045) — его нужно подключить к объявлениям.

## Контекст (бэкенд)
- `GET /api/complaints/reasons?lang=<язык>` → `[{code, title}]` — названия уже на языке
  пользователя (окно само их загружает).
- `POST /api/listings/{id}/complaints` `{reason, comment}` → `{accepted, message}`.
  401 — гость (окно предложит войти), 429 — больше 20 жалоб за сутки.
- 3 разных человека пожаловались — объявление само скрывается из поиска.

## Что сделать
1. Страница объявления (`ListingPage`): внизу, после блоков с информацией, неброская
   кнопка «🚩 Пожаловаться» — так же, как на странице гостиницы (`hotel-summary__complain`).
2. По нажатию — `<ComplaintModal path={`/api/listings/${id}/complaints`} … />`.
3. Успех — тост «Жалоба отправлена» (окно уже так делает) и окно закрывается. Повторная жалоба на то же
   объявление разрешена (сервер обновит причину).
4. Тексты уже есть в `t.complaint` на трёх языках; если добавляете новые — ka / ru / en.

## Проверка
- Отправить жалобу из Mini App → тост на языке интерфейса; в боте у владельца (`/admin`)
  жалоба видна.
- Гость в браузере → предложение войти.
- `npx tsc --noEmit` и `npm run build` без ошибок.
