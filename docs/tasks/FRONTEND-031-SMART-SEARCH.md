# FRONTEND-031: Умный поиск по смыслу

## Контекст (бэкенд TASK-012)
`GET /api/listings?q=<текст>&sort=smart` — объявления, близкие по смыслу к тексту
(«светлая двушка с балконом у метро»), с остальными фильтрами. Не больше 50 результатов.
Если AI недоступен, бэкенд сам вернёт обычный поиск по словам. Подробности —
`docs/tasks/TASK-012-SMART-SEARCH.md`.

## Что сделать
1. В строке поиска — переключатель «🧠 По смыслу» (по умолчанию включён, когда
   введён текст из 3+ букв). Включён — запрос с `sort=smart`.
2. Плейсхолдер строки поиска: «Опишите квартиру своими словами…» (ka / ru / en).
3. Когда включён «по смыслу», выбор сортировки из FRONTEND-044 не показывать (порядок — по смыслу).
4. Все тексты ka / ru / en.

## Проверка
- «квартира с балконом у метро» → сверху объявления с балконом и метро, даже без этих слов.
- `npx tsc --noEmit` и `npm run build` без ошибок.

## Ссылка из бота
Страница поиска должна открываться сразу с умным поиском по адресу
`/search?q=<текст>&sort=smart` (и `/?q=…&sort=smart` — главная перекидывает на `/search`):
читать `sort` из адреса и передавать его в `GET /api/listings`.
Тогда бот вернёт кнопку «📱 Открыть в приложении» под результатами умного поиска (сейчас
её там нет — сайт показал бы просто главную). Скажите владельцу, когда будет готово.
