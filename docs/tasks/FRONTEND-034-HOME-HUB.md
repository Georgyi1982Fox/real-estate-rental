# FRONTEND-034: Красивое главное меню Mini App (всё, что есть в боте)

## Контекст
В боте главное меню — 15 кнопок (поиск, посуточно, умный поиск, избранное, сдать
квартиру, Premium, пригласить друга, оплата аренды, профиль, помощь, поддержка,
документы). На сайте / в Mini App сейчас только лента объявлений — выглядит сухо.
Нужно, чтобы всё, что умеет бот, было видно и на сайте, и выглядело красиво.

Бэкенд готов: все API уже есть (ссылки ниже). Где API нет — кнопка открывает
нужный раздел бота ссылкой `https://t.me/<бот>?start=<раздел>`. Разделы: `search`,
`daily`, `smart`, `fav`, `owner`, `premium`, `invite`, `rent`, `profile`, `help`,
`support`, `terms`, `privacy` (бот сразу открывает этот раздел).

## Что сделать

### 1. Главный экран-«хаб» (над лентой объявлений на `/`)
- Сверху приветствие («Привет, {имя}!» / без имени — «Найдём квартиру в Грузии»)
  и строка поиска (существующий `SearchBar`).
- Две большие карточки-«героя» в ряд: **🔍 Поиск** (помесячно) и **🛏 Посуточно**.
  Градиентный фон, крупная иконка, подпись в одну строку (например «Квартиры на
  месяц и дольше» / «Квартиры на сутки и выходные»).
- Под ними — сетка плиток (2 колонки на телефоне, 4 на компьютере), сгруппированных
  как в боте:
  - **Искать:** 🧠 Умный поиск, ❤️ Избранное, 🔔 Сохранённые поиски, 📬 Уведомления
    (со счётчиком `GET /api/notifications/unread-count`).
  - **Хозяевам:** 🏠 Сдать квартиру.
  - **Выгода:** ⭐ Premium (показывать «активен до …», если подписка есть —
    `GET /api/subscription`), 🎁 Пригласить друга.
  - **Жильё:** 🗓 Оплата аренды.
  - **Ещё:** 👤 Профиль, ❓ Помощь, 💬 Поддержка, 📄 Соглашение, 🔒 Конфиденциальность.
- Плитка: скруглённые углы (16px), мягкая тень, иконка в цветном кружке (у каждой
  группы свой цвет), заголовок + короткая подпись серым. Нажатие — лёгкая анимация
  (scale 0.97). Поддержка тёмной темы Telegram (`themeParams`) и светлой.
- Ниже — лента объявлений как сейчас, с заголовком «Новые объявления».

### 2. Нижняя панель вкладок (на телефоне и в Mini App)
Пять вкладок, всегда внизу: **🏠 Главная · 🔍 Поиск · ❤️ Избранное · 🏠+ Сдать ·
👤 Профиль**. Активная вкладка подсвечена. На компьютере можно оставить меню в шапке.
Учесть отступ снизу iPhone (`env(safe-area-inset-bottom)`).

### 3. Куда ведёт каждая кнопка

| Кнопка | Куда | API / задача |
|---|---|---|
| 🔍 Поиск | лента с фильтрами, помесячно | `GET /api/listings` |
| 🛏 Посуточно | та же лента с `rent_period=daily` | FRONTEND-032 |
| 🧠 Умный поиск | поле «опишите квартиру словами», `sort=smart&q=…` | FRONTEND-031 |
| ❤️ Избранное | `/favorites` | есть |
| 🔔 Сохранённые поиски | `/searches` | есть |
| 📬 Уведомления | `/notifications` | есть |
| 🏠 Сдать квартиру | новая страница `/my-listings` | FRONTEND-033, `/api/my/listings` |
| ⭐ Premium | `/premium` | есть (+ FRONTEND-016) |
| 🎁 Пригласить друга | новая страница `/invite` | FRONTEND-029, `GET /api/referral` |
| 🗓 Оплата аренды | открыть бота: `https://t.me/<бот>?start=rent` (API нет, работает в боте) | — |
| 👤 Профиль | `/profile` | есть |
| ❓ Помощь | новая страница `/help`: что умеет Bina.ai, 6–8 вопросов-ответов (аккордеон) | — |
| 💬 Поддержка | открыть бота: `https://t.me/<бот>?start=support` | — |
| 📄 Соглашение | новая страница `/legal/terms` | `GET /api/legal/terms?lang=` |
| 🔒 Конфиденциальность | новая страница `/legal/privacy` | `GET /api/legal/privacy?lang=` |

Если задача из колонки «API / задача» ещё не сделана — плитку всё равно показать,
но вести на заглушку «Скоро» (красивую, с иконкой), чтобы меню было полным сразу.

Внутри Mini App ссылки на бота открывать через `Telegram.WebApp.openTelegramLink(...)`,
на обычном сайте — новой вкладкой (есть компонент `OpenInTelegram`).

### 4. Страница документов `/legal/:doc`
Заголовок, «Редакция от …» (`version_label`), вступление (`intro`), разделы
(`sections[].title` + `text`) — аккордеоном или с оглавлением. Язык — текущий язык сайта.

### 5. Тексты
Все надписи (заголовки плиток, подписи, «Скоро», вопросы помощи) — ka / ru / en,
как везде на сайте. Названия плиток — такие же, как кнопки бота
(`src/bina/infrastructure/bot/texts.py`, ключи `menu_*`), чтобы бот и сайт совпадали.

## Проверка
- На телефоне (ширина 375px) главная выглядит аккуратно: 2 колонки плиток,
  нижняя панель не перекрывает контент, нет горизонтальной прокрутки.
- В тёмной теме Telegram всё читается.
- Каждая из 15 плиток куда-то ведёт (страница, бот или «Скоро»).
- Переключение языка меняет все надписи.
- `npx tsc --noEmit` и `npm run build` без ошибок.
