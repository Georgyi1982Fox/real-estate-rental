# TASK-086: Сохранённые поиски со всеми фильтрами

## Проблема
В сохранённом поиске запоминались только районы, цена и комнаты. Этаж, удобства,
состояние, «только собственник», площадь и текст терялись, поэтому уведомления приходили
шире, чем человек выбрал.

## Что сделано
- Новая колонка `bina_saved_searches.details` (JSON, миграция `saved_search_details`):
  остальные фильтры под именами полей `ListingSearchFilters`.
- `POST /api/searches` → `filters` принимает те же фильтры, что `GET /api/listings`:

| Поле | Что |
|---|---|
| `min_area`, `max_area` | площадь, м² |
| `q` | текст поиска |
| `floor_min`, `floor_max` | этаж |
| `not_first_floor`, `not_last_floor` | не первый / не последний |
| `bedrooms`, `bathrooms` | спален / санузлов от |
| `features` | удобства (список кодов, нужны все) |
| `condition` | состояние (список кодов, любое) |
| `owner_only` | только собственники |

  Неизвестные коды удобств или состояния, `min_area > max_area`, `floor_min > floor_max` → 422.
- `GET /api/searches` возвращает все эти поля в `filters` (незаданные — `null`, `[]`, `false`).
- Уведомления о новых квартирах и счётчик «+N новых» учитывают все фильтры
  (`application/saved_searches.py: saved_search_filters`).
- Название по умолчанию: «Ваке, 2 комн., ещё фильтров: 3».

## Фронтенд
`FRONTEND-017-SAVE-ALL-FILTERS.md`: кнопка «Сохранить поиск» отправляет все выбранные фильтры.
