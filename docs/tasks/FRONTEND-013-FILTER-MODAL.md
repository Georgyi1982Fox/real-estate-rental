# FRONTEND-013: Фильтры во всплывающем окне ⏳ 1 день

## Контекст
Проект Bina.ai: Telegram Mini App для аренды жилья в Грузии. Фронтенд на **React + TypeScript + Vite**
(`frontend/src/`). Пути `frontend/templates/components/*.html` из старого плана устарели:
компоненты — это `src/components/*.tsx`.

**Что уже есть** (FRONTEND-009, PR #46): фильтры на главной работают и хранятся в адресе страницы
(`useSearchFilters`, `src/lib/searchFilters.ts`), `FilterPanel`, `PriceRange` (debounce 400 мс, проверка
цены), кнопка «Сбросить фильтры», «Сохранить поиск». Эта задача **переносит фильтры в окно** и
добавляет выбор нескольких районов. Логику фильтров не переписывать — переиспользовать.

## Бэкенд (готов)
Несколько районов:
```
GET /api/listings?district=<uuid1>,<uuid2>      (или district=<uuid1>&district=<uuid2>)
```
До 20 районов, показываются квартиры **в любом** из них. Один район работает как раньше.

Сохранённый поиск с несколькими районами:
```
POST /api/searches   { "filters": { "districts": ["<uuid1>", "<uuid2>"], "max_price": 2000 }, "notify": true }
```
В ответе `filters.districts` — все районы; `filters.district` — только если район ровно один
(старое поле остаётся, чтобы ничего не сломалось). Название по умолчанию: «Ваке, Сабуртало +1».

Типы в `src/api/types.ts`:
```ts
export interface SearchFilters {
  district?: string;      // оставить: старые сохранённые поиски
  districts?: string[];   // новое: несколько районов
  min_price?: number;
  max_price?: number;
  rooms?: number;         // 4 = «4 и больше»
}
```

## Что сделать

### 1. Кнопка «Фильтры» на главной
- Вместо панели фильтров на главной — кнопка **«⚙️ Фильтры»** рядом со строкой поиска.
- На кнопке счётчик выбранных фильтров: «Фильтры · 3» (район, цена, комнаты — каждый считается один раз).
- Под строкой поиска — **чипы** выбранных фильтров («Ваке», «до 2 000 ₾», «2 комн.») с ✕: нажатие
  убирает этот фильтр.
- «Сохранить поиск» и «Сбросить фильтры» остаются на главной, как сейчас.

### 2. Окно `src/components/FilterModal.tsx`
На телефоне — **лист снизу** (bottom sheet) во всю ширину, на компьютере — окно по центру.
Можно доработать существующий `Modal` (параметр `variant="sheet"`) или сделать новый компонент.

- **Районы** — кнопки-«таблетки» (chips) с мультивыбором, названия из `useDistricts` на языке
  интерфейса, отсортированы по алфавиту. Сверху поле «Найти район», если районов больше 12.
- **Цена** — существующий `PriceRange` («от» / «до», ₾).
- **Комнаты** — кнопки **1, 2, 3, 4+**, выбирается одна (повторное нажатие снимает выбор).
  Отдельной «Студии» нет: сайты-источники отдают студию как 1 комнату, поэтому подпись кнопки
  «1» — «1 / студия».
- Внизу закреплены кнопки **«Сбросить»** (очищает поля в окне) и **«Показать N квартир»**.
  N — число квартир под выбранные в окне фильтры: запрос `GET /api/listings?...&per_page=1`
  (поле `total`), с задержкой ~400 мс после изменения. Пока считается — «Показать…».
- Изменения применяются **только по «Показать»**: до этого адрес страницы и список не меняются.
  Закрытие окна (✕, фон, Esc, свайп вниз, кнопка «Назад» Telegram) — без применения.
- В Telegram можно использовать `MainButton` (хук `useTelegramMainButton` уже есть) вместо
  своей кнопки «Показать».

### 3. Анимация
- Открытие: фон плавно затемняется (150 мс), лист выезжает снизу (200–250 мс, `ease-out`).
- Закрытие — в обратную сторону. Уважать `prefers-reduced-motion` (без движения, только прозрачность).
- При открытом окне страница под ним не прокручивается.

### 4. Адрес страницы
- Несколько районов: `?district=<uuid1>,<uuid2>` (через запятую). Один район — как раньше.
- Обновить `parseFilters` / `entries` в `src/lib/searchFilters.ts` и `useSearchFilters`.
- Старые ссылки `?district=<uuid>` и старые сохранённые поиски (`filters.district`) продолжают работать.
- Сохранение поиска отправляет `districts` (массив), если районов больше одного.
- Карточка сохранённого поиска и «уже сохранено ✓» учитывают несколько районов
  (`filters.districts`).

### 5. Тексты
На трёх языках (ka, ru, en) в `src/i18n/strings.ts`: «Фильтры», «Районы», «Найти район»,
«1 / студия», «Показать {n} квартир» (с правильным склонением для ru), «Сбросить».

- Выбрал Ваке + Сабуртало, до 2000 ₾, 2 комнаты → «Показать 37 квартир» → список из обоих районов,
  в адресе `?district=…,…&max_price=2000&rooms=2`, на кнопке «Фильтры · 3», под поиском три чипа.
- ✕ на чипе убирает фильтр. После перезагрузки страницы фильтры на месте.

  главную с этими фильтрами.
- Старый сохранённый поиск с одним районом открывается правильно.
- `npx tsc --noEmit` и `npm run build` без ошибок.
