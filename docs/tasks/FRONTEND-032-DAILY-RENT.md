# FRONTEND-032: Посуточная аренда и новые сайты

## Контекст (бэкенд TASK-092)
Теперь собирается и **посуточная** аренда, и объявления ещё с двух сайтов:
**Livo.ge** и **Korter.ge**. Подробности — `docs/tasks/TASK-092-OTHER-SITES.md`.

- `GET /api/listings` по умолчанию возвращает **помесячную** аренду (как раньше).
  `rent_period=daily` — только посуточная.
- У каждого объявления поле `rent_period`: `"monthly"` (цена за месяц) или `"daily"`
  (цена **за сутки**).
- Сохранённые поиски: `filters.rent_period` (`monthly` по умолчанию / `daily`).
- Источники (`source` в фильтре и `also_on[].source`): `ss`, `myhome`, `livo`, `korter`,
  `telegram`.

## Что сделать
1. В поиске (и во всплывающих фильтрах) — переключатель **«Помесячно / Посуточно»**
   (по умолчанию «Помесячно»). «Посуточно» → запрос с `rent_period=daily`.
   Подсказки диапазона цены для посуточной — за сутки (например, до 80 / 80–120 /
   120–200 / от 200 ₾).
2. У цены посуточного объявления (карточка, страница объявления, избранное,
   сравнение) — приписка **«/ сутки»** (ka: «/ დღე», en: «/ day»).
3. «Сохранить поиск» передаёт `rent_period`; в списке поисков — пометка «посуточно».
4. Фильтр «Источник» (FRONTEND-019) и «Также на другом сайте» (FRONTEND-018):
   добавить **Livo.ge** и **Korter.ge**.
5. Все тексты ka / ru / en.

## Проверка
- Переключили на «Посуточно» — цены вида 50–150 ₾ с «/ сутки»; обратно — обычные.
- `npx tsc --noEmit` и `npm run build` без ошибок.
