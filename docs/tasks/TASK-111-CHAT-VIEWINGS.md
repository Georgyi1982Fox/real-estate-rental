# TASK-111 + TASK-112: Чат с хозяином с AI-переводом и запись на просмотр

## Решения владельца
- Переписка идёт **через бота**: арендатор пишет на своём языке, бот переводит на язык
  хозяина и пересылает, ответ — обратно. Telegram-имена друг другу не показываются.
- **Бесплатно** для всех. Защита от спама: не больше 5 новых диалогов в сутки у арендатора,
  не больше 3 неотвеченных просьб о просмотре.
- Время просмотра **предлагает арендатор**, хозяин отвечает «✅ Подходит» / «❌ Другое время».
  За 2 часа до подтверждённого просмотра бот напоминает обоим.

Работает только для объявлений, которые хозяева разместили сами (TASK-096, `source=owner`).

## Как пользоваться (бот)
1. В результатах поиска и в избранном под объявлениями хозяев есть кнопки **«💬 N»**
   (N — номер объявления). С сайта — ссылка `https://t.me/<бот>?start=chat_<id объявления>`.
2. Карточка квартиры: **«✍️ Написать хозяину»** и **«📅 Записаться на просмотр»**.
3. «Написать» → следующее сообщение уходит хозяину с переводом и оригиналом мелким шрифтом.
   У получателя кнопка **«↩️ Ответить»** (у арендатора ещё «📅 Записаться на просмотр»).
   «🏠 Главное меню» отменяет ввод.
4. «Просмотр» → день (сегодня … +6 дней) → час (10:00–20:00 по Тбилиси, не раньше чем
   через час; занятые подтверждёнными просмотрами часы не показываются) → хозяину
   приходит просьба с кнопками. Ответ хозяина приходит арендатору; при отказе — кнопки
   выбрать другое время или написать.
5. За 2 часа до просмотра — «⏰ Напоминание» обоим (с адресом, если он есть).

Перевод — AI (тот же ключ `LLM_API_KEY`). Нет ключа или AI не ответил — сообщение
доставляется без перевода. Одинаковый язык бота у обоих — без перевода.

## Кнопка «Написать» на сайте
У объявлений хозяев адрес объявления (`url`, в API — `source_url` и
`POST /api/listings/{id}/contact`) — ссылка в бота `https://t.me/<бот>?start=chat_<id>`,
а не личный Telegram хозяина. Новые объявления получают её при размещении (бот и API),
старые — при запуске бота.

## Как работает
- Таблицы `bina_conversations` (диалог «квартира — арендатор»), `bina_chat_messages`
  (оригинал, перевод, язык — контекст беседы), `bina_viewings` (время, статус
  `pending` / `confirmed` / `declined`, когда напомнили). Миграция `chat_viewings`
  применяется сама при обновлении.
- Напоминания проверяет сам бот раз в минуту, пока он запущен (`bot/viewing_reminders.py`).
