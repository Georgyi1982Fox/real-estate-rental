# TASK-073 / TASK-076: «Поделиться квартирой» и «Вам может понравиться»

## Поделиться квартирой (TASK-073)
Ссылка на квартиру — ссылка на бота: `https://t.me/<бот>?start=l_<id>`. Кто её откроет,
увидит в боте карточку квартиры:
- фото, заголовок, цена, комнаты, площадь, район (на своём языке);
- кнопки «☆ В избранное», «📱 Подробнее в приложении», «🌐 Открыть на сайте»,
  «📤 Поделиться» (переслать дальше);
- квартира хозяина (не своя) — сразу карточка с «Написать» и «Просмотр» (чат через бота).

Если объявление снято или скрыто — «Это объявление больше недоступно».

API для сайта: `GET /api/listings/{id}/share?lang=ru` →
`{url, text, telegram_url}`; `telegram_url` открывает окно Telegram «Переслать».
Работает и без входа (гость сайта тоже может поделиться).

## Вам может понравиться (TASK-076)
Подборка квартир, похожих на избранное. Без AI и бесплатно:
- по избранному собирается «вкус»: город, вид аренды (помесячно или посуточно), районы,
  комнаты и обычная цена (доллары пересчитываются в лари);
- из 300 свежих объявлений того же города и вида аренды каждое получает баллы за свой
  район, похожее число комнат и близкую цену;
- избранное в подборку не попадает, совсем непохожее — тоже.

В боте: «❤️ Избранное» → кнопка «✨ Вам может понравиться».
API: `GET /api/recommendations?limit=10` → `{items, based_on}`; `based_on = 0` — избранного
нет (показать подсказку «добавьте квартиры в избранное»).
