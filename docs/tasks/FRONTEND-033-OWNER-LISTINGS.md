# FRONTEND-033: «Сдать квартиру» в Mini App

## Контекст (бэкенд TASK-096)
Собственник размещает квартиру сам. В боте это уже работает («🏠 Сдать квартиру»);
в Mini App нужен такой же экран. Подробности API — `docs/tasks/TASK-096-OWNER-LISTINGS.md`.

## Что сделать
1. Раздел «Мои объявления» (`GET /api/my/listings`): карточки со статусом
   (🟢 в поиске / ⚪ снято / 🔴 скрыто модератором), кнопки «Снять» / «Вернуть»
   (`PATCH {active}`), «Изменить цену» (`PATCH {price}`). Кнопка «Разместить квартиру»
   (неактивна, если активных уже `limit`).
2. Форма размещения (`POST /api/my/listings`): город, район (текст с подсказками из
   `GET /api/districts?city=`), помесячно/посуточно, комнаты (1 / студия … 5+), площадь,
   цена + валюта, этаж / этажей (необязательно), описание (20–3000 знаков), удобства
   (коды как в фильтрах), телефон (обязателен, если у пользователя нет имени в Telegram —
   тогда сервер ответит 422).
3. Фото: после создания — загрузка по одному (`POST /api/my/listings/{id}/photos`,
   тело — файл, `Content-Type` картинки), до 10, с превью и удалением
   (`DELETE .../photos/{index}`). Показывать прогресс; ошибку 422 — «Это не фото».
4. Ошибки: 409 — «Можно держать в поиске не больше 5 объявлений».
5. Все тексты ka / ru / en.

## Где квартира
В форме размещения — необязательно: адрес (`address`) и точка на карте (`latitude`,
`longitude`, только в Грузии; например, выбор точки на карте Leaflet). Тогда объявление
показывается на карте точной меткой.

## Проверка
- Разместили квартиру с 3 фото — она сразу видна в поиске (`?source=owner`).
- `npx tsc --noEmit` и `npm run build` без ошибок.
