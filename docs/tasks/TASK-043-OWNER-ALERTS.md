# TASK-043: Сообщения владельцу о сбоях

Раз в час, в конце каждого запуска парсера, бот пишет владельцу (`ADMIN_TELEGRAM_IDS`) на его
языке, если:
- **сломался шаг** запуска: парсинг, подробности, дубли, карта, перевод, антифрод, аренда,
  Premium, уведомления — «⚠️ Bina.ai: сломался шаг «translate»: …»;
- **сайт не даёт объявлений два запуска подряд** (ss, myhome, telegram) — возможно, сайт
  изменился или блокирует парсер;
- **сервер мини-приложения не отвечает** (проверка `http://api:8000/api/health` изнутри Docker).

Когда проблема ушла — «✅ … снова работает». Об одной проблеме — не чаще раза в 6 часов.

Настраивать ничего не нужно: нужны только `BOT_TOKEN` и `ADMIN_TELEGRAM_IDS` в `.env`
(`API_HEALTH_URL` задан в `docker-compose.yml`). Если сломался сам парсер целиком (контейнер
не запускается), Docker перезапускает его сам (`restart: unless-stopped`).

## Код
`application/health_monitor.py` (правила), шаги и отправка — `scrapers/cli.py`
(`step`, `check_api_health`, `send_owner_alerts`), тексты — `bot/texts.py` (`alert_*`).
