# TASK-012: Умный поиск по смыслу

## Как работает
1. **Отпечатки.** Раз в час (шаг `embeddings` в расписании парсера, после перевода)
   каждое новое объявление превращается в вектор-«отпечаток смысла». В него идут
   характеристики (комнаты, площадь, цена, район, город, этаж, ремонт, удобства),
   заголовок и описание (по возможности на английском). Модель — text-embedding-3-small.
2. **Поиск.** Запрос («светлая двушка с балконом у метро») превращается в вектор той же
   моделью, выдача сортируется по близости. Совпадение слов не нужно, язык запроса
   (ka/ru/en) может не совпадать с языком объявления. Показываются 50 самых близких,
   остальные фильтры (город, район, цена, комнаты…) работают как обычно.

## Где видно
- **Бот:** просто напишите сообщение, что ищете: бот ответит «🧠 Умный поиск» со
  списком и кнопками ☆. Команды и кнопки работают как раньше. Если AI не настроен или
  не ответил — прежняя подсказка «Не понял…».
- **API:** `GET /api/listings?q=…&sort=smart` (с любыми фильтрами). Если AI не ответил —
  обычный поиск по словам (как `sort=relevance`).
- **Мини-приложение:** FRONTEND-031 (переключатель «по смыслу»).

## Настройки
Ничего настраивать не нужно: используется тот же ключ, что для перевода
(`LLM_API_KEY`, `LLM_BASE_URL` — AITUNNEL). Если сервис не знает модель,
в `.env` можно задать `EMBEDDINGS_MODEL`, а отдельный ключ — `EMBEDDINGS_API_KEY`
и `EMBEDDINGS_BASE_URL`. Сбой шага `embeddings` приходит владельцу в Telegram (TASK-043).

Посчитать отпечатки вручную: `docker compose exec scraper bina-scrape embeddings --limit 2000`.

Стоимость: очень дёшево (у OpenAI — 0,02 $ за миллион токенов; у AITUNNEL — по их
прайсу): тысяча объявлений — порядка цента, запрос в умном поиске — доли цента.
