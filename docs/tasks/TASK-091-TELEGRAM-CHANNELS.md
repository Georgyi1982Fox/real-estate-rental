# TASK-091: Объявления из Telegram-каналов

## Что делает
Каждый час вместе с сайтами парсер читает публичные Telegram-каналы с арендой в Тбилиси
через их веб-версию `https://t.me/s/<канал>` (без аккаунта). Пост — свободный текст,
поэтому поля объявления достаёт AI (AITUNNEL, та же модель, что для перевода):
город, район, цена и валюта, комнаты, спальни, площадь, этаж, адрес, телефон,
удобства и короткий заголовок.

Дальше — обычный путь: нормализация (доллары → лари), сохранение, склейка дублей с
SS.ge/MyHome (TASK-090), перевод, антифрод, уведомления.

## Что отбрасывается
- не долгосрочная аренда: продажа, посуточно, «ищу квартиру», реклама, новости канала;
- другой город (пока приложение только по Тбилиси, TASK-079);
- нет цены, комнат, площади или района;
- посты старше `TELEGRAM_MAX_AGE_DAYS` (21 день) и короче 40 символов.

Отброшенный пост запоминается (`bina_scrape_skips`, 30 дней) и AI больше не отправляется.
Уже сохранённые посты тоже не разбираются повторно — **AI платит только за новые посты**.
Объявление из поста снимается с поиска через 21 день (пост в канале остаётся навсегда).

## Каналы
По умолчанию (`scrapers/settings.py: DEFAULT_TELEGRAM_CHANNELS`): Forrentge, m2tbilis,
kvartiry_tbilisi_ge, nestydnye_kvartiry_tbilisi, tbilisi_kvartiry, kvartiry_tbilisi_arenda,
kvartiry_tbili_city, ApartameniTbilisi, kvartiry_v_tbilisii.

**Группы** (@kvartiry_in_tbilisi, @m2tbilisi, @SalesGeorgia, @flatget1) веб-версии не имеют:
их можно читать только через Telegram-аккаунт — отдельная задача. Боты — не источник.

## Настройки (`.env`)
| Переменная | По умолчанию | Что |
|---|---|---|
| `TELEGRAM_CHANNELS` | список выше | каналы через запятую; `-` — не читать каналы |
| `TELEGRAM_MAX_PAGES` | 5 | страниц с канала за запуск (дальше — только если всё новое) |
| `TELEGRAM_MAX_AGE_DAYS` | 21 | посты старше не берутся, объявления снимаются |

Без `LLM_API_KEY` каналы не читаются (разбирать посты нечем).

## Команды
- `docker compose exec scraper bina-scrape --source telegram --limit 30` — прочитать каналы сейчас.
- Результат: «telegram: найдено N, прошло проверку M, … сохранено K».

## Устройство
- `infrastructure/scrapers/telegram_scraper.py` — разбор страницы канала, карточки постов,
  `with_details` = AI-разбор.
- `infrastructure/llm/listing_extractor.py` + `prompts/extract_listing.py` — AI.
- `pipeline.run_scrape` — пропущенные объявления (для любого источника) не открываются снова.
- Фикстуры `tg_channel.html`, `tg_channel_old.html` — настоящие страницы каналов (телефоны и
  имена заменены).
