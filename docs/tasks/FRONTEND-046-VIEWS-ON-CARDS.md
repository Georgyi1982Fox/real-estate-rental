# FRONTEND-046: «👁 Просмотры» на карточках и подсказка «кто смотрел»

**Бэкенд готов** (TASK-121). Карточки теперь есть на главной аренды `/rent` (по страницам),
в поиске, избранном, «Недавно смотрели» и подборках — значок нужен везде, где `ListingCard`. Продолжение FRONTEND-043: там «👁 просмотры» видны только на
странице квартиры, теперь — и на карточках в списках, с подсказкой по нажатию.

## Контекст (бэкенд)
- Поле `views` (число) теперь есть у объявлений во всех списках: поиск, похожие,
  «Избранное», «Недавно смотрели», «Вам может понравиться».
- `GET /api/listings/{id}/views` (вход не нужен) →
  `{total, today, week, people, in_favorites}`:
  всего просмотров, сегодня, за 7 дней, сколько разных людей смотрели (из вошедших
  в аккаунт), у скольких квартира в избранном. Сам этот запрос просмотром не считается.
- **Имён того, кто смотрел, нет и не будет** — это личные данные. Показываем только числа.

## Что сделать
1. **Карточка объявления** (`ListingCard`, везде, где она используется): маленький значок
   «👁 12» рядом с датой или ценой — только если `views > 0`.
2. **Подсказка по значку.** На телефоне — по нажатию, на компьютере — при наведении курсора.
   Нажатие на значок **не открывает** объявление (остановить переход по карточке).
   При первом открытии подсказки — запрос `GET /api/listings/{id}/views`, пока грузится —
   маленький индикатор. Текст, например:
   > 👁 23 просмотра
   > Сегодня: 4 · За неделю: 12
   > Смотрели 8 человек
   > ★ В избранном у 3
   Нулевые строки не показывать (например, «В избранном у 0»). Закрытие — нажатие вне
   подсказки или повторное нажатие на значок.
3. **Страница квартиры:** «👁 N просмотров» рядом с датой (FRONTEND-043) — то же: нажатие
   открывает ту же подсказку.
4. Склонения: «1 просмотр / 2 просмотра / 5 просмотров», «1 человек / 2 человека /
   5 человек» — как в остальном приложении (`plural`).
5. Тексты на трёх языках (ka / ru / en).

## Проверка
- В поиске у квартир, которые открывали, виден «👁 N»; у новых — значка нет.
- Нажать на «👁» на карточке → подсказка с цифрами, объявление не открылось.
- Открыть квартиру ещё раз → вернуться → число на карточке выросло на 1.
- Переключить язык → подсказка на новом языке.
- `npx tsc --noEmit` и `npm run build` без ошибок.
