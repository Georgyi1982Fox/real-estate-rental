# TASK-107: Напоминание об окончании Premium

## Что происходит
Раз в час (в расписании парсера, перед отправкой уведомлений):
- **За 3 дня до окончания** — «⏳ Premium действует до 12.10.2026. Продлить: /premium — мгновенные
  уведомления о новых квартирах, анализ цены, договор и акт приёмки останутся с вами.»
- **После окончания** (если закончился не больше 7 дней назад) — «Premium закончился. Уведомления
  о новых квартирах теперь приходят с задержкой 3 часа. Продлить: /premium».

`/premium` в сообщении нажимается — бот показывает кнопки «Продлить на 7 / 30 дней».
Сообщения — служебные уведомления: приходят в Telegram и видны в списке уведомлений Mini App,
на языке пользователя (ka / ru / en). Служебные сообщения отправляются **без** 3-часовой
задержки бесплатного тарифа.

Каждое сообщение — один раз на срок окончания (`bina_users.premium_reminded_for`,
`premium_expired_notified_for`). После продления срок другой — напоминания придут снова.

Вручную: `docker compose exec scraper bina-scrape premium-reminders`, затем
`bina-scrape notify` (отправка). Вывод: `premium: напоминаний N, «закончился» N`.

Автопродления нет: звёзды Telegram оплачиваются разово, пользователь продлевает сам.

Миграция `premium_reminders` применяется сама при `update-bina.bat`.

## Код
`application/use_cases/premium_reminders.py` (тексты и правила),
`infrastructure/db/repositories/premium_reminders.py`, шаг в `scrapers/cli.py`,
`NotificationsRepository.list_unsent` (служебные — без задержки).
