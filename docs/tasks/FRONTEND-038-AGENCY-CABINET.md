# FRONTEND-038: Кабинет риелтора / агентства в Mini App (красиво)

## Контекст (бэкенд TASK-100)
Риелторы и агентства — главный источник дохода. Кабинет должен выглядеть современно и
дорого: риелтор платит, когда видит, что его объявления смотрят.
Подробности API — `docs/tasks/TASK-100-AGENCIES.md`.

## Что сделать
1. **Вход:** в профиле и на «Сдать квартиру» — карточка «💼 Вы риелтор или агентство?
   10 объявлений бесплатно» → форма: название, описание, телефон → `POST /api/agency`.
2. **Кабинет** (`GET /api/agency`), страница `/agency`:
   - шапка: логотип (загрузка — `POST /api/agency/logo`, тело = файл), название, описание
     (редактирование — `PATCH /api/agency`);
   - плашка пакета: «Бесплатный · 3 из 10 объявлений» с прогресс-баром; при `testing_mode`
     — «Тестовый режим: всё бесплатно»;
   - **статистика за 30 дней**: сверху 4 крупные цифры (просмотры, обращения, переписки,
     записи на просмотр — суммы по объявлениям), ниже — карточки объявлений с цифрами
     👁 💬 ✉️ 📅 ❤️ и бейджем «⭐ Premium до …» (`premium_until`);
   - кнопки «⭐ Сделать Premium» у объявления и «💳 Пакеты» — открывают бота
     (`https://t.me/<бот>?start=owner`), оплата звёздами там.
3. **Пакеты:** карточки из `plans` (объявлений, цена ⭐, `plan_days` дней) + Premium
   (`bump_price_stars` ⭐ / `bump_days` дней: «раз в сутки поднимается наверх»).
4. **Страница агентства** `/agency/:id` (`GET /api/agencies/{id}`): логотип, название,
   описание, сетка объявлений. Ссылкой можно делиться.
5. **В карточке объявления:** если `agency` не `null` — строка с логотипом и названием
   агентства (ссылка на его страницу); `is_premium_listing` — значок «⭐».
6. Тексты ka / ru / en, тёмная тема, 375px.

## Проверка
- Регистрация → кабинет с лимитом 10; статистика растёт после просмотров с другого аккаунта.
- Страница агентства открывается по ссылке без входа.
- `npx tsc --noEmit` и `npm run build` без ошибок.
