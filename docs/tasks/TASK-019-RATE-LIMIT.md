# TASK-019: Защита от перегрузки (rate limiting)

## API (Mini App)
С одного посетителя (IP; за Cloudflare — настоящий IP из заголовка `CF-Connecting-IP`):
- **120 запросов в минуту** — всего;
- **20 в минуту** — «тяжёлые» запросы: договор и акт приёмки (PDF), AI-помощник, счёт на оплату,
  жалобы, применение приглашения.

Сверх лимита — ответ **429** «Too many requests, try again in N s» с заголовком `Retry-After`.
`/api/health` не ограничивается. Лимиты — в памяти процесса API (у нас он один).

## Бот
Больше **20 сообщений и нажатий за 10 секунд** от одного человека — лишние отбрасываются ещё до
обращения к базе; человек один раз получает «⏳ Слишком много сообщений подряд…» (на своём языке).

## Настройки (`.env`, необязательно)
| Переменная | По умолчанию | Что это |
|---|---|---|
| `API_RATE_LIMIT` | 120 | запросов в минуту с одного IP (0 — без ограничения) |
| `API_HEAVY_RATE_LIMIT` | 20 | «тяжёлых» запросов в минуту с одного IP |
| `BOT_RATE_LIMIT` | 20 | сообщений и нажатий за 10 секунд от одного человека |

У AI-помощника дополнительно остаётся дневной лимит (TASK-095), у жалоб — 20 в сутки (TASK-106).

## Код
`infrastructure/ratelimit` (скользящее окно), `api/rate_limit.py` (middleware),
`bot/middlewares/throttling.py`.
