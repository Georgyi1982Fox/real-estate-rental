## Что сделано

### Вид аренды: помесячно / посуточно
- `application/rent_period.py`: `monthly`, `daily`; `period_from_text` — «посуточно»
  в тексте умного поиска.
- Колонка `bina_listings.rent_period` (миграция `listing_rent_period`, всё старое —
  `monthly`), `RawListing.rent_period`.
- **Поиск по умолчанию — помесячная аренда**: у посуточной цена за сутки, в одном списке
  это сбивает с толку. `ListingSearchFilters.rent_period` (`None` — любая).
- Не смешиваются: похожие объявления, «дешевле похожие», анализ цены, медианы района,
  антифрод (AI знает, что цена за сутки), поиск дублей между сайтами, текст для
  умного поиска («per day»).
- **API:** `GET /api/listings?rent_period=daily` (по умолчанию `monthly`); у объявления
  поле `rent_period`; сохранённые поиски — `filters.rent_period`, название
  «Батуми, посуточно, 1 комн.».
- **Бот:** в `/search` на шаге бюджета кнопка «🛏 Посуточно» / «📅 Помесячно» (свои
  диапазоны цен за сутки: до 80, 80–120, 120–200, от 200 ₾); в карточке «50 ₾ / сутки»;
  текст «квартира посуточно в Ваке» ищет посуточную аренду.

### Источники
- **livo.ge** — `scrapers/livo_scraper.py`. Список: `/v1/statements?deal_types=2,7&
  real_estate_types=1&cities=1,15`, объявление целиком: `/v1/statements/{id}`, язык
  `locale: ru` (заголовки, районы и перевод описания на русском — как у myhome).
  VIP-объявления стоят в начале выдачи вне порядка дат и не учитываются при остановке
  «дальше только известные». Телефон API отдаёт замаскированным — не сохраняем.
  Перепроверка старых объявлений тоже идёт через API.
- **korter.ge** — `scrapers/korter_scraper.py`. Разделы
  `/ru/аренда-квартир-<город>` и `/ru/аренда-квартир-посуточно-<город>`; берутся только
  квартиры (`propertyCategory: flat`, `section: rent | daily_rent`). У объявлений нет
  заголовка — собираем «3-комнатная квартира, Крцаниси».
- **ss.ge** — добавлен раздел посуточной аренды (`/ru/недвижимость/l/Квартира/Аренда--за-день`,
  `dealType 3`).
- **myhome.ge** — добавлен поиск посуточной аренды (`deal_types=7`). ⚠️ С облачного
  компьютера myhome не открывается, адрес проверить вживую нельзя. Если в логах
  сборщика myhome посуточных нет — открыть на myhome.ge посуточную аренду, скопировать
  адрес в `.env` → `MYHOME_DAILY_SEARCH_PATH` (и `..._BATUMI`), номер страницы → `{page}`.
- **Telegram-каналы** — посты про посуточную аренду больше не отбрасываются, AI отмечает
  их `daily`.
- Разбор объявлений TNET (myhome + livo) — общий файл `scrapers/tnet.py`. Если район не
  указан (часто в Батуми) — объявление относится к городу в целом.
- Расписание: `myhome, ss, livo, korter` (+ telegram), раз в час.

### Настройки (`.env`, всё необязательно)
`LIVO_MAX_PAGES`, `LIVO_SEARCH_QUERY`, `KORTER_MAX_PAGES`, `KORTER_SEARCH_PATH[_BATUMI]`,
`KORTER_DAILY_SEARCH_PATH[_BATUMI]`, `SS_DAILY_SEARCH_PATH` (`-` — не собирать),
`MYHOME_DAILY_SEARCH_PATH[_BATUMI]` (`-` — не собирать).
