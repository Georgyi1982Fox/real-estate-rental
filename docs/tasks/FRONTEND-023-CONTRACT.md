# FRONTEND-023: «Договор аренды» в объявлении (Premium)

## Контекст (бэкенд TASK-101)
`POST /api/listings/{id}/contract` → бот присылает PDF договора в чат
(`{"sent": true, "filename": "…"}`). Поля анкеты — в `docs/tasks/TASK-101-CONTRACT.md`.
Без Premium — 402, ошибки в полях — 422, бот не смог отправить — 502.

## Что сделать
1. На странице объявления кнопка **«Договор аренды»** (с пометкой Premium).
2. Форма (один экран, прокрутка):
   - Хозяин: имя*, паспорт/ID; Арендатор: имя*, паспорт/ID.
   - Адрес (подставить из объявления, если есть; иначе обязательно).
   - Дата начала*, срок в месяцах* (кнопки 3 / 6 / 12 + своё число).
   - Плата и валюта (подставить из объявления), депозит (по умолчанию = плата).
   - Платить до числа (1-28), коммунальные: «платит арендатор / хозяин / включены».
   - «Можно с животными» (переключатель), дополнительные условия (текст).
   - Второй язык договора: русский / английский (по умолчанию — язык интерфейса).
3. Кнопка «Получить договор» → запрос с `delivery: "chat"`. Успех: «Договор отправлен
   в чат с ботом» и кнопка «Открыть чат» (`Telegram.WebApp.close()` или ссылка на бота).
4. Загрузка: индикатор, не давать нажать дважды.
5. 402 — окно «Подключить Premium» (как в FRONTEND-011); 422 — подсветить поля;
   502 — «Запустите бота (/start) и попробуйте ещё раз».
6. Все тексты ka / ru / en — при английском интерфейсе всё на английском.

## Проверка
- С Premium договор приходит в чат; без Premium — окно Premium.
- `npx tsc --noEmit` и `npm run build` без ошибок.
