# TASK-041: Ежедневный отчёт владельцу и проверка безопасности

## Ежедневный отчёт

Раз в день, в 9:00 по Тбилиси (`DAILY_REPORT_HOUR`), бот присылает владельцу
(`ADMIN_TELEGRAM_IDS`) сводку за сутки на его языке:

- пользователи: всего и новых;
- объявления в поиске: всего и новых, новых от хозяев и риелторов;
- агентства: всего и новых;
- новые чаты и заявки на просмотр;
- оплаты и звёзды за сутки, сколько Premium сейчас;
- запросы к AI-помощнику;
- что ждёт решения: открытые жалобы и заявки «я собственник».

Отчёт уходит один раз в день, даже если парсер перезапускали: отправленные дни записываются в
`bina_daily_reports`. Если компьютер был выключен в 9:00, отчёт придёт при первом запуске
после этого часа. `DAILY_REPORT=0` выключает отчёт. Прислать сейчас:
`docker compose exec scraper bina-scrape daily-report`.

### Код
- `application/daily_report.py`: цифры отчёта и правило «когда пора».
- `AdminRepository.daily` / `claim_daily_report`.
- `scrapers/cli.py`: `daily_report`, шаг расписания `report`, команда `daily-report`.
- Текст `daily_report` в `bot/texts.py`.

## Проверка безопасности (октябрь 2026)

Проверены вход через Telegram (подпись initData), доступ к чужим данным в API и в кнопках бота,
оплата звёздами, загрузка файлов, HTML в сообщениях бота, секреты в логах и CORS. Серьёзных
дыр не найдено. Исправлено:

| Что было | Что сделано |
|---|---|
| Телефоны хозяев можно было собрать скриптом без входа | Номер хозяина (`source=owner`) — только вошедшим через Telegram (иначе 401) |
| У скрытых модератором и снятых объявлений можно было взять телефон и написать хозяину | Телефон, «Написать» и чат — только у объявлений в поиске |
| Три одноразовых аккаунта скрывали любое объявление, даже сразу после решения модератора | Автоскрытие — только по жалобам аккаунтов старше суток; решённую жалобу нельзя открыть снова; оплаченные («Топ», Premium) и проверенные объявления сами не скрываются |
| Оплату могла «съесть» защита от флуда или сбой ответа бота | Оплаты не ограничиваются; платёж сохраняется до ответа пользователю |
| Тело запроса частями (chunked) обходило лимит размера | Без `Content-Length` — 411 |
| «Картинка-бомба» до 50 Мп | До 25 Мп, только JPEG/PNG/WEBP/GIF |
| Фото, логотип и умный поиск — 120 запросов в минуту | Они в «тяжёлых» (20 в минуту) |
| «Снял — разместил заново» без конца | Не больше «лимит + 5» новых объявлений за сутки |
| Заголовку `CF-Connecting-IP` верили от любого адреса | Только от туннеля (этот компьютер / сеть Docker) |
| Занятые часы показа — по любому объявлению; номер риелтора — чужая карточка | Проверка объявления; только свой номер из Telegram |

Осталось на решение владельца: `PREMIUM_FOR_ALL=1` (режим тестирования) перед запуском для
людей выключить — иначе AI бесплатно всем; накрутка рефералов вторым аккаунтом — принятый
риск.
