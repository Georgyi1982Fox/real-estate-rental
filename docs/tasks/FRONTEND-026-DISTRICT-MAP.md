# FRONTEND-026: Карта и «О районе» в объявлении

## Контекст (бэкенд TASK-080, TASK-104)
- `GET /api/listings/{id}/location` → `precision` (`exact` / `district` / `none`), `latitude`,
  `longitude`, `district`, `address`, `links.google / yandex / osm`.
- `GET /api/districts/{id}` → справка по району: время до центра, метро, метки, описание,
  число объявлений, обычные цены по комнатам. Тексты уже на языке пользователя.
- Подробности — `docs/tasks/TASK-104-DISTRICT-MAP.md`.

## Что сделать
1. **Карта в карточке объявления**: Leaflet + плитки OpenStreetMap (бесплатно, без ключа;
   подпись © OpenStreetMap обязательна). Высота ~200 px, без прокрутки колесом.
   - `exact` — метка на точке, масштаб ~16;
   - `district` — круг радиусом ~700 м и подпись «Примерно: район Ваке», масштаб ~14;
   - `none` — карту не показывать.
   Под картой кнопки «Google Maps» и «Яндекс Карты» (`Telegram.WebApp.openLink(url)`).
2. **Блок «О районе»** (по `district_id` объявления): название, «~15 мин до центра»,
   «метро рядом» / «без метро», метки-чипы, описание (если есть), «42 объявления в поиске»,
   «Обычно: 1-комн. ~1 100 ₾, 2-комн. ~1 650 ₾», мелко — `note`.
   Кнопка «Все квартиры в районе» → поиск с фильтром по району.
3. Все тексты ka / ru / en (переключили язык — всё на новом языке).

## Проверка
- Объявление с SS.ge — точная метка; из Telegram без адреса — круг «примерно».
- `npx tsc --noEmit` и `npm run build` без ошибок.
