# FRONTEND-026: Карта в объявлении и «О районе»

Сейчас на странице объявления в блоке «Расположение» заглушка «Карта скоро появится»
(`ListingPage.tsx`, строка с `lt.map_soon`). Её нужно заменить настоящей картой.

## Бэкенд (готов, TASK-080 / TASK-104)
- `GET /api/listings/{id}/location?lang=ru` → `precision` (`exact` / `district` / `none`),
  `latitude`, `longitude`, `district` (название на языке), `address`,
  `links.google / yandex / osm`. **Работает и без входа** (гость сайта): тогда язык
  берётся из `?lang=`, в Telegram — язык пользователя.
- В самом объявлении (`GET /api/listings/{id}`) уже есть `latitude` / `longitude`, но
  точность (`exact` / `district`) знает только `/location` — берите её оттуда.
- Хозяева при размещении ставят точку на карте (шаг «📍 Где квартира?») — у их объявлений
  обычно `exact`.
- `GET /api/districts/{district_id}?lang=ru` → справка о районе (тоже без входа): время до
  центра, метро, метки, описание, число объявлений, обычные цены по комнатам, `note`.

## Что сделать
1. **Карта** вместо заглушки: Leaflet + плитки OpenStreetMap (бесплатно, без ключа;
   подпись «© OpenStreetMap» обязательна). Высота ~200 px, без прокрутки колесом мыши
   (чтобы страница прокручивалась), перетаскивание пальцем — да.
   - `exact` — метка на точке, масштаб ~16;
   - `district` — круг радиусом ~700 м и подпись «Примерно: район Ваке», масштаб ~14;
   - `none` — блок карты не показывать (оставить только адрес, если есть).
   Под картой кнопки «Google Maps» и «Яндекс Карты» (в Telegram —
   `Telegram.WebApp.openLink(url)`, в браузере — новая вкладка).
2. **Блок «О районе»** (по `district` объявления): название, «~15 мин до центра»,
   «метро рядом» / «без метро», метки-чипы, описание (если есть), «42 объявления в поиске»,
   «Обычно: 1-комн. ~1 100 ₾, 2-комн. ~1 650 ₾», мелко — `note`.
   Кнопка «Все квартиры в районе» → `/search?district=<id>`.
3. Тексты ka / ru / en (переключили язык — всё на новом языке).

## Проверка
- Объявление хозяина с точкой — метка на месте; объявление без адреса — круг «примерно»;
  без района и адреса — карты нет.
- В браузере без входа карта тоже показывается.
- `npx tsc --noEmit` и `npm run build` без ошибок.
