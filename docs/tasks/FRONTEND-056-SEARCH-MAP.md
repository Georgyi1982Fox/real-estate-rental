# FRONTEND-056: Квартиры на карте в поиске

## Зачем
Квартиру выбирают по месту: рядом с работой, метро, морем в Батуми. Список этого не показывает.

## Что отдаёт бэкенд (готово)
У каждой квартиры в `GET /api/listings` есть `latitude` и `longitude` (у SS.ge и MyHome.ge —
точные; у Telegram-каналов и части других — `null`). Отдельного запроса не нужно: карта
показывает ту же страницу результатов, что и список (`per_page` до 50).

## Что сделать
1. В поиске (`SearchPage`) переключатель «☰ Список / 🗺 Карта». Выбор — в адресе страницы
   (`view=map`), чтобы «Назад» со страницы квартиры возвращал на карту, а ссылкой с картой
   можно было поделиться.
2. На карте — точки квартир текущей страницы результатов (на карте брать `per_page=50`).
   Нажали точку → внизу маленькая карточка (фото, цена, комнаты, район) → нажали → страница
   квартиры. Цена прямо на точке (`1 500 $`) — если удобно читать; иначе просто точки.
3. Карта подстраивается, чтобы были видны все точки. Квартиры без координат — строка
   «Ещё N квартир без точки на карте — смотрите в списке».
4. Фильтры, сортировка и страницы 1 2 3 работают и на карте (другая страница → другие точки).
5. Leaflet — только в части карты (`lazy`), в основной `index-*.js` не попадает. Плитки и
   подпись © OpenStreetMap — как в `components/ListingMap.tsx`.
6. Свайп карты внутри Telegram не должен закрывать Mini App и прокручивать страницу
   (вертикальные свайпы уже выключены в `lib/telegram.ts` — проверить на телефоне).

Тексты — на трёх языках (ka / ru / en).

## Проверка
- В демо-базе координат нет — для проверки задать нескольким квартирам:
  `UPDATE bina_listings SET latitude = 41.709 + random()/50, longitude = 44.76 + random()/50
  WHERE id IN (SELECT id FROM bina_listings WHERE status = 'active' LIMIT 30);`
- Поиск → «🗺 Карта»: точки на месте; нажали точку → карточка → квартира → «Назад» → снова карта.
- Поменяли фильтр — точки обновились; страница 2 — другие точки.
- Выбрали другой город — карта переехала туда (если у его квартир есть точки).
- Размер основного `index-*.js` не вырос (Leaflet в отдельной части).
- `npx tsc --noEmit` и `npm run build` без ошибок.
