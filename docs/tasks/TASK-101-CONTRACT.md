# TASK-101: Двуязычный договор аренды в PDF (Premium)

## Что умеет
`POST /api/listings/{id}/contract` — пользователь заполняет анкету, бэкенд собирает PDF:
грузинский текст слева, русский или английский справа, пункт в пункт. 11 пунктов:
стороны, предмет (адрес, комнаты, площадь), срок, плата и день оплаты, депозит,
коммунальные, животные, обязанности сторон, расторжение (за 30 дней), споры (право Грузии).
Плюс пункт 12 «Дополнительные условия», если они заданы. В конце — подписи и дисклеймер
«это образец, при необходимости обратитесь к юристу».

Анкета (JSON):
| Поле | Обязательно | Что это |
|---|---|---|
| `landlord_name`, `tenant_name` | да | Имена сторон (2-120 символов) |
| `landlord_id`, `tenant_id` | нет | Паспорт / ID (до 40) |
| `address` | если нет в объявлении | Адрес квартиры (до 200) |
| `start_date` | да | Дата начала, `2026-11-01` |
| `months` | да | Срок, 1-60 месяцев |
| `rent`, `currency` | нет | Плата и валюта (`GEL`/`USD`/`EUR`); по умолчанию — из объявления |
| `deposit` | нет | Депозит, по умолчанию 0 |
| `payment_day` | нет | До какого числа платить, 1-28 (по умолчанию 1) |
| `utilities` | нет | Кто платит коммунальные: `tenant` (по умолчанию), `landlord`, `included` |
| `pets_allowed` | нет | Можно ли с животными (по умолчанию нет) |
| `notes` | нет | Дополнительные условия (до 500) |
| `second_language` | нет | `ru` / `en`; по умолчанию язык пользователя (для `ka` — `en`) |
| `delivery` | нет | `chat` (по умолчанию) — бот присылает PDF в чат; `file` — PDF в ответе |

Ответы:
- `delivery=chat` → `{"sent": true, "filename": "bina-contract-2026-11-01.pdf"}`, файл приходит
  в чат с ботом с подписью на языке пользователя. Из Mini App так проще всего сохранить
  файл и переслать хозяину.
- `delivery=file` → `application/pdf` (скачивание).

## Ограничения
- Только Premium, иначе **402**.
- Нет адреса ни в анкете, ни в объявлении, или неверные поля — **422**.
- Бот не смог отправить файл (пользователь не запускал бота или заблокировал его) — **502**.
- Нет `BOT_TOKEN` — **503**.

## Код
- `application/contract.py` — пункты на ka / ru / en.
- `infrastructure/documents/pdf.py` — общие части PDF (для акта приёмки TASK-102 тоже).
- `infrastructure/documents/contract_pdf.py` — сборка договора.
- `infrastructure/api/routes/contract.py` — API.
- Шрифт DejaVu Sans (есть грузинские буквы) лежит в `infrastructure/documents/fonts/`
  с лицензией. Библиотека — `fpdf2`.
