# TASK-124: свой адрес Mini App для владельца (российский туннель Tuna)

## Почему
Сайт Mini App работает через Cloudflare (`https://bina.test-realtybot.ru`). Российские провайдеры
замедляют Cloudflare: страница бесконечно грузится. У других людей (и из Грузии) всё открывается,
а у владельца — нет, даже на своём компьютере по этому адресу. На самом компьютере
`http://127.0.0.1:5173` открывается — значит, приложение в порядке, не пускает только сеть.

## Что сделано
- `BOT_OWNER_MINI_APP_URL` в `.env` — адрес Mini App **только для владельца** (`ADMIN_TELEGRAM_IDS`):
  - кнопка «Открыть» у поля ввода в его чате (`setup_bot_ui`, меню чата владельца);
  - все кнопки Mini App в ответах бота (`OwnerAppUrlMiddleware` подменяет `settings` через
    `BotSettings.for_user`);
  - кнопки «Открыть» в уведомлениях (`TelegramNotificationSender`, парсер).
  Пусто — у владельца общий адрес (его кнопка меню сбрасывается на общую).
- `TUNA_SUBDOMAIN` в `.env` — `start-bina.bat` открывает окно «Bina - tunnel RU»:
  `tuna http 5173 --subdomain=<поддомен>`. Тот же сайт из Docker (порт 5173), что и у Cloudflare.
- Остальные люди открывают приложение как раньше, через Cloudflare.

## Tuna (tuna.am)
Российский сервис туннелей: точки входа в России и Европе, провайдеры РФ его не режут.
Бесплатно: постоянный поддомен `<имя>.ru.tuna.am` (раздел «Домены» в https://my.tuna.am).
На бесплатном тарифе при первом заходе из браузера Tuna показывает страницу-предупреждение
(один раз) — для владельца это нормально; для всех пользователей этот путь не годится.

## Настройка у владельца (Windows, один раз)
1. `winget install --id yuccastream.tuna` — затем закрыть и заново открыть PowerShell.
2. `tuna login` — вход через браузер (регистрация на tuna.am).
3. `tuna http 5173` — в выводе строка `Your permanent free domain: <имя>.ru.tuna.am`;
   остановить `Ctrl+C`.
4. `notepad .env` — добавить две строки и сохранить:
   `BOT_OWNER_MINI_APP_URL=https://<имя>.ru.tuna.am` и `TUNA_SUBDOMAIN=<имя>`.
5. `.\update-bina.bat`, затем `.\start-bina.bat` (откроется окно «Bina - tunnel RU»).
6. В Telegram: закрыть приложение, в чате бота нажать «Открыть» у поля ввода. Первый раз —
   страница Tuna, нажать «Продолжить». Если приложение открылось «без входа» — закрыть и
   открыть ещё раз.
