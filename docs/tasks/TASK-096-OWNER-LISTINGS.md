# TASK-096: Собственник сам размещает квартиру (+ TASK-024, 025, 030, 031)

## Решения владельца (30.09.2026)
- Размещение **сначала в боте**; для Mini App готов API, экран делает друг (FRONTEND-033).
- Объявление **сразу в поиске**, с автопроверкой (антифрод, как у сайтов); владельцу
  сервиса приходит сообщение с кнопкой «🚫 Скрыть».
- Фото хранятся **на компьютере владельца** (том Docker `media`), при переезде на сервер
  (TASK-088) — перенесём.

## Бот
Кнопка главного меню «🏠 Сдать квартиру» и команда `/mylistings`:
- список своих объявлений (🟢 в поиске / ⚪ снято / 🔴 скрыто модератором), кнопки
  «Снять №N» / «Вернуть №N», «Цена №N»;
- «✍️ Разместить квартиру» — мастер: город → район (текстом) → помесячно/посуточно →
  комнаты (1 / студия … 5+) → площадь → цена (лари, `$`, `€`) → этаж (`5/9`, можно
  пропустить) → описание (20–3000 знаков, любой язык) → фото (1–10, можно альбомом) →
  телефон (кнопка «Отправить номер», текстом или «Только через Telegram», если есть имя
  пользователя) → проверка → «✅ Опубликовать».
- Заголовок собирается сам на трёх языках: «2-комн. квартира, Ваке, 60 м²»; описание
  переводит AI, как у объявлений с сайтов.
- Не больше **5 активных** объявлений у человека.
- Ответы мастера хранятся в памяти бота: после перезапуска начать заново.
- Кнопки меню внизу во время мастера — не ответ: они открывают свой раздел.

## Хранение
- `bina_listings.owner_user_id` (миграция `listing_owner`), `source_name = "owner"`,
  `owner_type = "owner"`, `url` — `https://t.me/<имя>` (кнопка «Написать»), телефон — в `phone`.
- Фото (TASK-024/025): `infrastructure/storage/photos.py` — проверка, что это картинка,
  поворот по EXIF, уменьшение до 1600 px, JPEG 85 %, без EXIF (координаты съёмки не
  сохраняются). Папка `MEDIA_DIR` (в Docker — том `media`, `/app/media`), адрес
  `/api/media/listings/<id>/<файл>.jpg`.
- Бэкап (`scripts/backup.sh`) докопирует фото в `backups/media`.

## Модерация (TASK-030, TASK-031)
Сообщение владельцу сервиса (`ADMIN_TELEGRAM_IDS`): карточка, начало описания, число
фото и кнопка «🚫 Скрыть» (та же, что в админке для жалоб; вернуть — «Вернуть» в
разборе жалоб). Антифрод и жалобы работают как для остальных объявлений.

## API для Mini App
| Метод | Что делает |
|---|---|
| `GET /api/my/listings` | свои объявления (`status`: `active` / `off` / `hidden`) и `limit` |
| `POST /api/my/listings` | разместить: `city`, `district` (текст), `rent_period`, `price`, `currency`, `rooms`, `area`, `floor`, `total_floors`, `description`, `phone`, `features`; 201 |
| `PATCH /api/my/listings/{id}` | `price` (+`currency`), `active` (false — снять, true — вернуть) |
| `POST /api/my/listings/{id}/photos` | тело — сам файл (JPEG/PNG/WebP, до 15 МБ), по одному, до 10 |
| `DELETE /api/my/listings/{id}/photos/{index}` | удалить фото |

Ошибки: 409 — уже 5 активных, 422 — нет телефона и имени в Telegram / не фото / неверные
данные, 404 — не своё объявление. Имя пользователя Telegram берётся из подписанных данных
Mini App. В поиске собственники — источник `owner` (`?source=owner`).

## Где квартира (точка на карте)
После района бот спрашивает «📍 Где именно квартира?»: точка на карте (📎 → «Геопозиция»,
только в Грузии) или адрес текстом; можно пропустить. Точка — сразу точная метка на карте
(`GET /api/listings/{id}/location` → `precision: exact`); адрес без точки найдёт шаг
«geocode» парсера. В API (`POST /api/my/listings`) — поля `address`, `latitude`, `longitude`.
