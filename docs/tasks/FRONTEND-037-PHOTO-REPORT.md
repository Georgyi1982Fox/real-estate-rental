# FRONTEND-037: «Ремонт по фото» (AI) в карточке и на странице объявления

## Контекст (бэкенд TASK-114)
AI смотрит фото квартиры и оценивает ремонт; Premium видит подробный разбор.
Подробности — `docs/tasks/TASK-114-PHOTO-ANALYSIS.md`.

## Что сделать
1. **Карточка и страница объявления:** если `repair_level` не `null` — значок
   «🛠 Отличный ремонт» (зелёный) / «🛠 Хороший ремонт» (нейтральный) /
   «🛠 Нужен ремонт» (оранжевый). Подпись мелко: «по фото, оценка AI».
2. **Страница объявления — блок «Что видно на фото»:** `GET /api/listings/{id}/photo-report`.
   - Premium (`premium_required: false`): список `issues[].label` с иконками
     предупреждения и текст `summary`. Пока ответ грузится (AI может думать до 30 с) —
     скелетон «AI смотрит фото…».
   - Без Premium (`premium_required: true`): уровень и размытый блок
     «Плесень, трещины, техника — подробный разбор в Premium» с кнопкой «Premium».
   - 404 — блока нет; 503 / 429 — тихо скрыть блок.
   - Нужен вход (`X-Telegram-Init-Data`); без входа (401) блок не показывать.
   - Место блока — под «Описанием» (`ListingDescription`), кнопка «Premium» ведёт на `/premium`.
   - Ответ: `level` (`excellent` / `good` / `needs_repair`), `level_label` (уже на языке
     пользователя), `issues[]` (`code`, `label`), `summary`, `premium_required`.
3. Тексты ka / ru / en.

Оценку ремонта ставит AI владельца. Если `repair_level` у квартир пока пустой, для проверки
подставьте ответ в DevTools (Overrides) или поменяйте `repair_level` в тестовой базе.

## Проверка
- Объявление с `repair_level` показывает значок в ленте и на странице.
- Premium видит список проблем и вывод, без Premium — приглашение в Premium.
- `npx tsc --noEmit` и `npm run build` без ошибок.
