# FRONTEND-027: Сравнение квартир

## Контекст (бэкенд TASK-105)
`GET /api/listings/compare?ids=a,b,c` → `rows` (код и подпись строки на языке пользователя),
`items` (значения по каждой квартире + `listing` как в списке), `best` (строка → ID лучших),
`note`. Подробности — `docs/tasks/TASK-105-COMPARE.md`.

## Что сделать
1. Кнопка «Сравнить» (значок весов) на карточке в списке и в избранном: отмечает до 3 квартир.
   Внизу экрана плашка «Сравнить (2)» → экран сравнения. Выбор хранить в `localStorage`.
2. Экран сравнения: колонки — квартиры (фото, название), строки — из `rows` в их порядке.
   Лучшее значение в строке (`best`) выделить цветом. Удобства — галочками, `price_level` и
   `risk_level` — теми же бейджами, что в карточке (FRONTEND-020, 021).
3. На телефоне — горизонтальная прокрутка колонок, первая колонка с подписями закреплена.
4. Убрать квартиру из сравнения — крестик в колонке; осталась одна — вернуть к списку.
5. Все тексты ka / ru / en.

## Проверка
- Выбрали 2-3 квартиры → таблица, лучшее выделено; 4-я не добавляется (подсказка «максимум 3»).
- `npx tsc --noEmit` и `npm run build` без ошибок.
