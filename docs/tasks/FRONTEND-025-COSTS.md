# FRONTEND-025: «Сколько это стоит на самом деле» в объявлении

## Контекст (бэкенд TASK-103)
`GET /api/listings/{id}/costs?people=2&months=12&start=2026-11&deposit_months=1&agency_fee_percent=0&utilities_included=false`
— все параметры необязательные, суммы в лари. Поля — в `docs/tasks/TASK-103-COSTS.md`.
Названия статей (`items[].title`) и пояснение (`note`) уже на языке пользователя.

## Что сделать
1. В карточке объявления блок **«Полная стоимость»**:
   - «При въезде: N ₾» (`first_month.total`) с расшифровкой: аренда, залог, комиссия, коммунальные.
   - «В среднем в месяц: N ₾» (`average_month`), «Коммунальные: ~N ₾».
   - «За N месяцев: N ₾» (`period_total`).
2. Настройки (меняют запрос): сколько человек, срок, месяц въезда, залог (0 / 1 / 2 месяца),
   комиссия агента (0 / 50 / 100%), «коммунальные включены». Если `agent_listing` — подсказка
   «Объявление от агента: уточните комиссию».
3. График или список по месяцам (`monthly`): зимой коммунальные заметно выше.
4. Под блоком мелко — `note`. Если аренда не в лари — «по курсу 1 $ = 2,7 ₾».
5. Все тексты ka / ru / en.

## Проверка
- Меняем число людей и срок — суммы пересчитываются.
- `npx tsc --noEmit` и `npm run build` без ошибок.
