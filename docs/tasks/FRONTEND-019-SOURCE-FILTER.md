# FRONTEND-019: Фильтр «Источник» (SS.ge, MyHome.ge, Telegram)

## Контекст
Теперь объявления приходят из трёх источников: SS.ge, MyHome.ge и Telegram-каналов (TASK-091).
`GET /api/listings` принимает `source` — через запятую, любой из: `ss`, `myhome`, `telegram`.
Неизвестный источник — 422.

## Что сделать
1. В окне фильтров (FRONTEND-013) — блок «Источник»: три переключателя-чипа SS.ge,
   MyHome.ge, Telegram. Ничего не выбрано — все источники.
2. Выбранное — в `source` запроса и в адрес страницы (`?source=telegram`), как другие фильтры.
3. В карточке объявления — маленький значок источника (для Telegram — «Telegram», у поста
   ссылка `https://t.me/<канал>/<id>` открывается через `openTelegramLink`, это уже работает).
4. Тексты ka / ru / en.

## Проверка
- Выбран только Telegram — в списке только объявления с `source_url` на `t.me`.
- `npx tsc --noEmit` и `npm run build` без ошибок.
