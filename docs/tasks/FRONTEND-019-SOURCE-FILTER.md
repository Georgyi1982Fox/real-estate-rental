# FRONTEND-019: Фильтр «Сайт» (SS.ge, MyHome.ge, Livo.ge, Korter.ge, Telegram, хозяева)

## Контекст (бэкенд готов)
Объявления собираются с пяти сайтов и от хозяев напрямую (TASK-091, TASK-092, TASK-096).
`GET /api/listings` принимает `source` — через запятую, любой из:
`ss`, `myhome`, `livo`, `korter`, `telegram`, `owner` (объявления хозяев на Bina.ai).
Неизвестный код — 422. У каждого объявления есть поле `source` (тот же код) и `source_url`.
Названия сайтов уже есть в одном словаре: `frontend/src/lib/sources.ts` (из FRONTEND-018).

## Что сделать
1. В окне фильтров (FRONTEND-013) — блок «Сайт»: чипы SS.ge, MyHome.ge, Livo.ge, Korter.ge,
   Telegram, «От хозяев на Bina.ai». Ничего не выбрано — все.
2. Выбранное — в `source` запроса и в адрес страницы (`?source=ss,myhome`), как другие
   фильтры; в метках под поиском — «Сайт: SS.ge ✕». В «Сохранить поиск» сайт пока
   **не передавать** — сохранённые поиски его ещё не хранят (бэкенд добавит позже).
3. На карточке объявления — маленькая подпись сайта внизу (например, «MyHome.ge») по полю
   `source`, текст из `lib/sources.ts`; `owner` — «Bina.ai».
4. Тексты ka / ru / en.

## Проверка
- Выбран только Korter.ge — у всех карточек подпись Korter.ge.
- Выбраны SS.ge и Telegram — в адресе `?source=ss,telegram`, обновили страницу — фильтр тот же.
- `npx tsc --noEmit` и `npm run build` без ошибок.
