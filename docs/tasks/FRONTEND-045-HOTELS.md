# FRONTEND-045: Раздел «Гостиницы» (этап 1)

## Контекст (бэкенд TASK-120, готов)
Новый раздел: гостиницы, гостевые дома, хостелы, апарт-отели. Их размещают сами
пользователи (не собираются с сайтов). С квартирами **не смешивать** — отдельная вкладка.
Подробности API — `docs/tasks/TASK-120-HOTELS.md`.

- `GET /api/hotels/options` — коды: `kinds`, `room_kinds`, `amenities`, `currencies`,
  `sorts`, `limits`. Тексты к кодам — во фронтенде (ka / ru / en).
- `GET /api/hotels?city=&kind=a,b&guests=&price_min=&price_max=&stars=&amenities=a,b&sort=&page=&per_page=`
  → `{items, total, page, pages}`; карточка: `id, kind, name, city, address, stars,
  amenities, images, min_price (₾ за ночь, «от»), max_guests, latitude, longitude,
  is_promoted, is_verified`.
- `GET /api/hotels/{id}` — ещё `description` (`{ka?, ru?, en?}` — показать язык
  интерфейса, если есть, иначе любой), `check_in`, `check_out`, `rooms[]`
  (`id, kind, title, guests, price, currency, count`), `has_phone`, `has_whatsapp`,
  `has_telegram`.
- `GET /api/hotels/{id}/contact` (нужен вход, иначе 401) → `phone`, `whatsapp_url`,
  `telegram_url`.
- `POST /api/hotels/{id}/complaints` `{"reason": "...", "comment": ""}` — причины как у
  квартир (`GET /api/complaints/reasons`).
- Хозяину — `/api/my/hotels` (см. TASK-120): создать, изменить, снять/вернуть, удалить,
  фото по одному (тело запроса — файл), номера.

## Что сделать
1. **Вкладка / плитка «🏨 Гостиницы»** на главной и в меню. Город — из общего выбора
   города (FRONTEND-030).
2. **Поиск гостиниц** `/hotels`: фильтры — тип, гостей, цена за ночь от/до, звёзды,
   удобства; сортировка (`newest`, `price_asc`, `price_desc`, `stars_desc`); карточка —
   фото, название, тип, звёзды, «от N ₾ / ночь», значки «🔥 Топ», «✅».
   Без объектов — понятный пустой экран и кнопка «Разместить свою гостиницу».
3. **Страница объекта** `/hotels/{id}`: галерея, название, тип, звёзды, адрес и карта
   (как у квартир), удобства значками, заезд/выезд, описание, таблица номеров
   (тип, гостей, цена за ночь, «N номеров»).
   Кнопки: «📞 Позвонить», «WhatsApp», «Telegram» (по `has_*`; номер — из `/contact`,
   гостю без входа — «Войдите, чтобы увидеть контакты»), «Пожаловаться».
4. **Мои гостиницы** `/my/hotels`: список со статусом (в поиске / снят / скрыт
   модерацией), «Разместить», «Изменить», «Снять / Вернуть», «Удалить».
5. **Форма размещения** (шаги): тип и название → город, адрес, точка на карте → звёзды,
   удобства, заезд/выезд → описание → номера (добавить несколько: тип, гостей, цена,
   валюта, сколько) → телефон и WhatsApp → фото (после создания — по одному, до 20).
   Ошибка 422 `rejected: <коды>` — показать по-человечески:
   `link_in_text` — «Уберите ссылки из текста», `contact_in_text` — «Телефон и почту
   укажите в полях контактов, не в описании», `bad_description` — «Описание от 30
   знаков», `bad_name` — «Проверьте название», `bad_price` — «Цена ночи от 10 до 5 000 ₾».
   409 — «Можно держать 5 объектов: снимите один», 429 — «На сегодня лимит, завтра».
6. Все тексты ka / ru / en.

## Проверка
- Разместить гостевой дом в Батуми с двумя номерами → он в поиске Батуми, «от» — цена
  самого дешёвого номера.
- В описании «пишите t.me/...» → понятная ошибка, объект не создан.
- Снять объект → пропал из поиска, в «Мои гостиницы» — «снят».
- `npx tsc --noEmit` и `npm run build` без ошибок.
