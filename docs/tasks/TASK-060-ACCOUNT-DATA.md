# TASK-059 / TASK-060: Скачать свои данные и удалить аккаунт

Нужно по законам о личных данных (Грузия, GDPR) и для проверки Telegram перед запуском.

## Бот
«👤 Профиль» → под языками две кнопки:
- **📦 Скачать мои данные**: бот присылает файл `bina-my-data.json` со всем, что хранится
  о человеке: профиль, оплаты, избранное, поиски, уведомления, напоминания, свои объявления,
  кабинет агентства, переписка и показы, жалобы, заявки «я собственник», запросы к AI.
- **🗑 Удалить аккаунт** → предупреждение (что удалится; оплаченный Premium пропадёт) →
  «Да, удалить всё» / «Отмена».

## Что происходит при удалении
- Удаляются избранное, поиски, уведомления, напоминания, переписка и показы (у обоих
  участников), жалобы, заявки «я собственник», счётчики AI, кабинет агентства с логотипом.
- Свои объявления снимаются: телефон, имя, адрес, точка на карте и фото стираются
  (файлы фото тоже удаляются с диска).
- Запись пользователя остаётся только как пустая: Telegram ID заменяется случайным
  отрицательным числом, подписка, баланс и код приглашения обнуляются. К ней привязаны
  платежи: их нужно хранить для бухгалтерии, но они больше ни с кем не связаны.
- Если человек снова напишет боту, он начнёт с чистого листа (новая запись).

## API (для Mini App, FRONTEND-040)
- `GET /api/me/export`: JSON-файл со всеми данными.
- `DELETE /api/me?confirm=true` → 204. Без `confirm=true` → 400.
