# FRONTEND-051: «Избранное» не засчитывает просмотры

## Что не так сейчас
`hooks/useFavoriteListings.ts` загружает каждую избранную квартиру отдельным
`GET /api/listings/{id}`. Этот запрос — «открыли объявление»:
- каждой квартире в избранном добавляется просмотр «👁» (FRONTEND-046), счётчики завышены;
- все избранные квартиры попадают в «Недавно смотрели» (FRONTEND-043);
- при 30 избранных — 30 запросов через туннель.

## Что сделать
1. Загружать избранное списком: `GET /api/favorites?page=N&per_page=50` (нужен вход).
   Ответ — как у поиска (`ListingsPageOut`: `items`, `total`, `page`, `pages`), у квартир уже
   есть `views`. Новые сверху. Страницы — пока не кончатся (у человека до 1000 избранных).
2. `GET /api/listings/{id}` из «Избранного» больше не вызывать.
3. Сохранить то, что работает сейчас:
   - добавили или убрали ♥ — список меняется сразу, без перезагрузки. Для только что
     добавленной квартиры есть данные карточки: `listingPreview(id)` (`lib/listingPreview.ts`);
   - заметки (`/api/favorites/notes`), «⚖ Сравнить», пустое состояние, ошибка с «Повторить»;
   - удалённых квартир (сейчас на них 404) в ответе нет — как и сейчас, их просто не видно.

## Проверка
- Откройте «Избранное» три раза подряд: у квартир не растёт «👁», «Недавно смотрели» не меняется.
- В DevTools → Network при открытии «Избранного» есть `/api/favorites`, нет `/api/listings/{id}`.
- Добавили ♥ в поиске → квартира сразу в «Избранном»; убрали → пропала.
- `npx tsc --noEmit` и `npm run build` без ошибок.
