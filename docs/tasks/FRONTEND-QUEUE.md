## Общие правила (для каждой задачи)
- Тексты на трёх языках (ka / ru / en); переключили язык — всё на новом языке.
- Внутри Telegram запросы с `X-Telegram-Init-Data`; в браузере без входа — там, где
  бэкенд отвечает 401, блок не показывать или предложить войти.
- Перед pull request: `npx tsc --noEmit` и `npm run build` без ошибок.
- Мержит владелец (через Claude) после проверки — сами свой PR не мержите, даже если CI зелёный.
- Страница квартиры открывается сразу с данными карточки (`lib/listingPreview.ts`), описание
  без перевода приходит из `GET /api/listings/{id}/text` (TASK-123). Новым блокам страницы
  хватает `listing.id` — не ждите полного ответа сервера.
- Mini App у владельца (bina.test-realtybot.ru) — собранный сайт в Docker: изменения видны
  после мержа и `update-bina.bat`.
- В описании PR — номер задачи (например, `FRONTEND-026`).
