# FRONTEND-039: Телефон хозяина — только после входа

**Бэкенд готов.** `GET /api/listings/{id}/phone` для объявлений, размещённых хозяевами у нас
(`source === "owner"`), без входа через Telegram теперь отвечает **401** (защита номеров от
сбора скриптами). Объявления с сайтов (ss, myhome…) — как раньше.

## Что сделать
- `PhoneReveal`: на 401 не показывать «Ошибка, повторить», а кнопку
  «Войдите через Telegram, чтобы увидеть номер» (тот же вход, что для избранного).
- Внутри Telegram Mini App ничего не меняется: initData уже передаётся.
- Если объявление скрыто или снято, `/phone` и `/contact` отвечают 404: показать
  «Объявление больше не в поиске» вместо кнопок связи.

## Проверка
- В браузере без входа: объявление хозяина → кнопка входа, объявление с ss.ge → номер.
- В Telegram: номер хозяина показывается.
