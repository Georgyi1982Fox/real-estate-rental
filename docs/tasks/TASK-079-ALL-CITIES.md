# TASK-079: Вся Грузия (не только Тбилиси и Батуми)

Раньше бот собирал объявления только из Тбилиси и Батуми, остальные города Грузии сайты
отдавали, но мы их отбрасывали. Теперь сервис знает все заметные города Грузии и собирает
объявления по всей стране.

## Что знает сервис
`bina.application.cities` — список городов с названиями на трёх языках, центром на карте и
границами для проверки адресов. Кроме Тбилиси и Батуми: Кутаиси, Рустави, Зугдиди, Гори,
Поти, Телави, Мцхета, Кобулети, Боржоми, Бакуриани, Гудаури, Цхалтубо, Кварели, Сигнахи,
Степанцминда (Казбеги), Ахалцихе, Озургети, Зестафони, Хашури, Сенаки, Марнеули, Гонио,
Уреки, Анаклия.

Город объявления определяется по номеру города сайта или по названию на любом языке. Город,
которого в списке нет (посёлок, муниципалитет), не попадает в поиск — но и не подписывается
неправильно «Тбилиси», как было раньше.

## Откуда берутся объявления
- **ss.ge** отдаёт объявления всей Грузии в одной выдаче — теперь мы правильно распознаём
  город каждого и сохраняем все.
- **Livo.ge**: если выбраны все города, фильтр по городу в запросе убираем — берём всю
  Грузию и отсеиваем лишнее у себя.
- **myhome.ge** и **korter.ge** собирают Тбилиси и Батуми (у них у каждого города свой адрес
  поиска). Другие города при желании добавляются в `.env` (`MYHOME_SEARCH_PATH_*`).

## Настройка
`SCRAPE_CITIES` в `.env`: пусто или `all` — вся Грузия (по умолчанию); можно сузить, например
`tbilisi,batumi`.

## Выбор города
- В боте шаг «Город» появляется сам, когда объявления есть больше чем в одном городе.
- В Mini App `GET /api/cities` отдаёт только города, где уже есть объявления (пустые не
  показываем). `GET /api/listings?city=…` и `/api/districts?city=…` проверяют код города.

## Код
`application/cities.py` (список городов), `scrapers/settings.py` (`SCRAPE_CITIES`),
`scrapers/ss_scraper.py`, `scrapers/livo_scraper.py`, `api/routes/cities.py`,
`api/routes/common.py` (`valid_city`).
