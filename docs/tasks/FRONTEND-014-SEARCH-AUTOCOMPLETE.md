# FRONTEND-014: Строка поиска с подсказками ⏳ 1 день

## Контекст
Проект Bina.ai: Telegram Mini App для аренды жилья в Грузии. Фронтенд на **React + TypeScript + Vite**
(`frontend/src/`). Путь `frontend/templates/components/search_bar.html` из старого плана устарел:
компонент — `src/components/SearchBar.tsx`.

**Сейчас строка поиска на главной ничего не делает**: поле не связано с адресом страницы и с
запросом к API, кнопка «Найти» только вибрирует. Бэкенд поиска по словам готов давно (TASK-022).

## Бэкенд (готов)
```
GET /api/listings?q=<текст>&...другие фильтры
GET /api/districts            → районы с названиями на ka/ru/en
```
- `q` ищет по заголовку и описанию на трёх языках, учитывает формы слов («ваке» найдёт «Ваке»,
  «ремонтом» — «ремонт») и начало слова («сабур» → «Сабуртало»). До 100 символов.
- При `q` сервер сам ставит сверху самые подходящие (`sort=relevance`). Не передавать `sort`,
  если пользователь не выбрал сортировку сам.
- **Улиц отдельно в базе нет**: сайты-источники не отдают улицу отдельным полем. Поэтому подсказки —
  только районы, а улица, метро или название комплекса ищутся самим поиском по словам
  (если они есть в тексте объявления).

## Что сделать

### 1. Поиск работает (главное)
- Текст из строки → параметр **`q`** в адресе страницы и в запросе `/api/listings`.
- Поиск по **Enter** и по кнопке «Найти». Пустая строка убирает `q`.
- При смене `q` страница сбрасывается на первую (как при смене фильтров в `useSearchFilters`).
- После перезагрузки страницы текст на месте (берётся из `q`).
- **Кнопка очистки ✕** внутри поля, когда в нём есть текст: очищает поле и убирает `q`.
- «Сбросить фильтры» сбрасывает и `q`.
- Нет результатов: `EmptyState` «По запросу «…» ничего не найдено» и кнопка «Сбросить поиск».

### 2. Подсказки районов
- При вводе от 2 символов — выпадающий список до 6 районов, у которых название (на любом из трёх
  языков) **содержит** введённый текст, без учёта регистра. Данные — `useDistricts`, без запросов
  на каждую букву. Название показывать на языке интерфейса.
- **Подсветка совпадения**: совпавшая часть названия жирным (`<mark>` или `<strong>`).
- Последняя строка списка: «🔍 Искать «<текст>»» — обычный поиск по словам.
- **Выбор района** из списка: район добавляется в фильтр районов (как в окне фильтров,
  FRONTEND-013), поле поиска очищается, `q` не ставится.
- **Клавиатура**: ↑/↓ — выбор строки, Enter — применить, Esc — закрыть список.
  Доступность: `role="combobox"`, `aria-expanded`, список `role="listbox"`, строки `role="option"`,
  `aria-activedescendant`.
- Список закрывается при клике вне поля и после выбора.

### 3. Тексты
На трёх языках (ka, ru, en) в `src/i18n/strings.ts`: плейсхолдер «Район, улица, метро…»,
«Искать «{q}»», «Очистить», «Ничего не найдено».

## Проверка
- Ввёл «ремонт», Enter → список отфильтровался, в адресе `?q=ремонт`, после перезагрузки текст на месте.
- ✕ очищает поле и возвращает полный список.
- Ввёл «саб» → в подсказках «**Саб**уртало» с подсветкой; выбрал → район добавился в фильтры,
  на кнопке «Фильтры» счётчик увеличился.
- Стрелки, Enter и Esc работают; мышью и пальцем тоже.
- Поиск работает вместе с фильтрами: `?q=балкон&district=…&max_price=2000`.
- `npx tsc --noEmit` и `npm run build` без ошибок.
