# TASK-117: Главное меню бота кнопками

## Что видит пользователь
- **При входе (`/start`)** — приветствие и сообщение «🏠 Bina.ai — главное меню» со всеми
  функциями кнопками:
  `🔍 Поиск` `❤️ Избранное` / `📱 Открыть Bina.ai` (если задан `BOT_MINI_APP_URL`) /
  `⭐ Premium` `🎁 Пригласить друга` / `🗓 Оплата аренды` `👤 Профиль` / `❓ Помощь`
  `💬 Поддержка` / `📄 Соглашение` `🔒 Конфиденциальность`;
  владельцу ещё `📊 Админка`.
- **Внизу чата всегда** кнопки `🔍 Поиск`, `❤️ Избранное`, `👤 Профиль` и **`🏠 Главное меню`** —
  из любого места возвращает в начало (и сбрасывает незаконченный ввод, например суммы аренды).
- **Под ответами** (помощь, Premium, приглашение, аренда, профиль, избранное) — кнопка
  `🏠 Главное меню`.
- Всё на языке пользователя: русский, английский, грузинский.

Команды (`/search`, `/premium`, `/rent`…) работают как раньше.

## Код
`bot/keyboards/menu.py` (`home_menu`, `with_home`, клавиатура внизу чата),
`bot/handlers/menu.py` (кнопки меню открывают те же разделы, что и команды),
`bot/handlers/start.py`.

**Правило:** у каждой команды из меню команд есть кнопка в главном меню. Тест
`test_every_command_has_a_menu_button` падает, если новую команду добавили без кнопки.
