# TASK-017: Проверка объявлений на мошенничество

> В `BACKEND_ROADMAP.md` это **TASK-011 «AI Детекция мошенничества»**.

## Как работает
Каждое новое (или изменённое) объявление проверяется один раз:

1. **Правила** (без AI):
   | Признак | Баллы | Код |
   |---|---|---|
   | Цена за м² < 40% медианы района (та же валюта, от 5 объявлений) | +40 | `price_far_below_market` |
   | Цена за м² < 60% медианы района | +20 | `price_far_below_market` |
   | Нет фото | +10 | `no_photos` |
2. **AI** (AITUNNEL, та же модель, что для перевода) читает текст и факты (цена, медиана района,
   фото) и ставит 0–100 с кодами причин:
   `prepayment` (предоплата до просмотра, перевод на карту), `off_platform` (только мессенджер,
   без звонков и просмотра), `urgency` (давят сроком), `too_good` (элитное почти даром),
   `vague` (нет адреса и деталей), `owner_abroad` («хозяин за границей, ключи пришлём»).
   Промпт просит быть осторожным: агентства, комиссия, залог при подписании — это норма.
3. **Итог** = AI + правила (не больше 100):

| Итог | Уровень | Что происходит |
|---|---|---|
| 0–39 | `none` | ничего |
| 40–79 | `warning` | ⚠️ «Есть признаки мошенничества: не платите до просмотра» (бот, Mini App) |
| 80–100 | `high` | скрыто из поиска и уведомлений; по прямой ссылке открывается с предупреждением |

Правила дают максимум 50, поэтому **сами по себе объявление не скрывают** — только вместе с AI.

Проверка повторяется, если у объявления изменились текст, цена или появились/пропали фото.

## Когда запускается
- Автоматически в сервисе `scraper`: парсинг → перевод → **проверка** (до 200 за раз) → уведомления.
  Проверка идёт до уведомлений, чтобы мошенники в них не попадали.
- Вручную: `docker compose exec scraper bina-scrape fraud --limit 200`.
  Одновременно работает только одна проверка (как и перевод).

Стоимость: один запрос к AI на объявление, примерно как перевод.

## API
В каждом объявлении (`GET /api/listings`, `/api/listings/{id}`, избранное):
```json
{ "fraud_level": "warning", "fraud_reasons": ["price_far_below_market", "no_photos"] }
```

## Что сделано
| Слой | Файлы |
|---|---|
| Политика | `application/fraud.py`: правила, сумма, пороги 40/80 |
| Порт, use case | `application/ports/fraud.py`, `application/use_cases/check_fraud.py` |
| AI | `infrastructure/llm/prompts/detect_fraud.py`, `infrastructure/llm/fraud_analyzer.py` |
| БД | миграция `listing_fraud`: `fraud_reasons`, `fraud_checked_at`; медиана цены за м² по району; скрытие в поиске |
| CLI | `bina-scrape fraud`, шаг в `schedule` (`--fraud-limit`) |
| API, бот | `fraud_level`, `fraud_reasons`; ⚠️ в списках бота |
| Тесты | правила, разбор ответа AI, use case и поиск на PostgreSQL, CLI, бот |

3. ✅ Автоматически после парсинга, вручную командой
4. ✅ Тесты, в том числе на PostgreSQL
