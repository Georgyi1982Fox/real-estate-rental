# FRONTEND-012: Предупреждение о мошенничестве ⏳ 0,5 дня

## Контекст
Бэкенд проверяет каждое объявление на мошенничество (правила + AI,
`docs/tasks/TASK-017-FRAUD.md`). Самые подозрительные уже скрыты из поиска.
Остальным нужно показать предупреждение.

## Перед началом
```bash
git checkout develop
git pull
git checkout -b feature/frontend-012-fraud-badge
```

## API
В каждом объявлении (`/api/listings`, `/api/listings/{id}`, `/api/favorites`) два новых поля.
Тип `Listing` в `src/api/types.ts`:
```ts
export type FraudLevel = 'none' | 'warning' | 'high';

export interface Listing {
  // ...
  fraud_level: FraudLevel;     // warning — предупредить; high — скрыто из поиска, но открывается по ссылке
  fraud_reasons: string[];     // коды, см. таблицу
}
```

## Что сделать
1. **Карточка в списке** (`ListingCard`): при `fraud_level !== 'none'` — жёлтый значок ⚠️ в углу
   фото, `title`/`aria-label`: «Есть признаки мошенничества».
2. **Страница объявления** (`ListingPage`): над кнопками связи — блок-предупреждение:
   - `warning`: жёлтый фон, «⚠️ Есть признаки мошенничества. Не платите и не переводите залог до
     просмотра квартиры и подписания договора.» и список причин (из таблицы);
   - `high`: красный фон, «🚫 Похоже на мошенничество», тот же совет и причины.
3. **Тексты** на трёх языках в `src/i18n/strings.ts`.

## Проверка
- Объявление с `fraud_level: "warning"` (можно временно подменить ответ) показывает ⚠️ в списке и
  блок с причинами на странице.
- `none` — ничего не меняется.
- `npx tsc --noEmit` и `npm run build` без ошибок.

## Definition of Done
1. ⏳ Значок ⚠️ на карточке

3. ⏳ Тексты ka/ru/en
4. ⏳ Сборка и проверка типов проходят
