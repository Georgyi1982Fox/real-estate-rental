# FRONTEND-041: «Поделиться» и «Вам может понравиться»

**Бэкенд готов** (TASK-073, TASK-076).

## 1. Кнопка «📤 Поделиться» на странице квартиры
- По нажатию: `GET /api/listings/{id}/share?lang=<язык>` → `{url, text, telegram_url}`.
- Внутри Telegram: `Telegram.WebApp.openTelegramLink(telegram_url)` — откроется окно
  «Переслать» с выбором чата.
- В браузере: `navigator.share({title: text, url})`, если есть; иначе скопировать `url` в
  буфер и показать «Ссылка скопирована».
- Ответ 503 — бот не настроен: кнопку спрятать.

Получатель откроет ссылку в Telegram и увидит карточку квартиры в боте с фото и кнопкой
«Подробнее в приложении».

## 2. Блок «✨ Вам может понравиться»
- `GET /api/recommendations?limit=10` (нужен вход через Telegram) →
  `{items: Listing[], based_on: number}`.
- Где показать: на странице «Избранное» под списком (горизонтальная лента карточек) и,
  по желанию, на главной (хабе).
- `based_on === 0` — вместо ленты подсказка «Добавьте квартиры в избранное ★ — подберём
  похожие». `items` пустой при `based_on > 0` — «Похожих пока нет, загляните позже».
- Карточки — те же, что в поиске (с ★ и переходом на страницу квартиры).

Тексты на трёх языках (ka/ru/en).

## Проверка
- Поделиться квартирой из Mini App → открыть ссылку с другого аккаунта → в боте карточка.
- Добавить 2–3 квартиры в избранное → в блоке появились похожие (того же района/цены),
  избранного среди них нет.
