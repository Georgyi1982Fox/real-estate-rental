# FRONTEND-055: «📉 Цена снижена» — на карточках, на странице квартиры и в поиске

## Зачем
Сайты часто снижают цену, если квартира не сдаётся. Это повод написать хозяину и
поторговаться. Сейчас о снижении узнают только из уведомлений об избранном (Premium).

## Что отдаёт бэкенд (готово)
У квартиры в `GET /api/listings`, `GET /api/listings/{id}`, избранном и других списках:
- `old_price: number | null` — прежняя цена, **если подешевело за последние 30 дней**
  (в той же валюте, что `price`; подорожало или снижение давнее — `null`);
- `price_dropped_at: string | null` — когда снизилась (ISO-дата).

Поиск: `GET /api/listings?price_dropped=true` — только подешевевшие за 30 дней (вместе с
любыми другими фильтрами и сортировками). В сохранённые поиски этот фильтр не сохраняется.

## Что сделать
1. **Карточка квартиры** (`ListingCard`, а также карточки в избранном, сравнении и т. д. —
   где показывается цена): старая цена зачёркнута рядом с новой и значок `📉 −13%`
   (процент округлить, считать от `old_price`).
2. **Страница квартиры**: под ценой — «📉 Цена снижена 3 дня назад: было 1 500 $» (дата —
   как в других местах, `timeAgo` / `smartDate`).
3. **Поиск**: в фильтрах — переключатель «📉 Только подешевевшие». В адресе страницы —
   `price_dropped=1` (как другие фильтры в `lib/searchFilters.ts`), работает «Назад» и
   ссылки из бота. При сохранении поиска этот фильтр не сохраняется — подсказка рядом
   с кнопкой «Сохранить» не нужна, просто не передавать.
4. **Главная аренды `/rent`**: блок «📉 Подешевели» — до 10 карточек
   (`price_dropped=true&per_page=10`), ссылка «Все» → поиск с этим фильтром. Нет таких
   квартир — блок не показывать.
5. `api/types.ts`: поля `old_price?`, `price_dropped_at?` у `Listing`.

Тексты — на трёх языках (ka / ru / en).

## Проверка
- Локально: у любой квартиры в базе сделать «снижение»:
  `UPDATE bina_listings SET previous_price = price + 200, price_changed_at = now() WHERE id = '…';`
  → на карточке зачёркнутая цена и `📉`, на странице квартиры — строка «Цена снижена…»,
  квартира в блоке «📉 Подешевели» и в поиске с фильтром.
- `price_changed_at = now() - interval '40 days'` → значков нет, в фильтре квартиры нет.
- Переключили язык — все новые тексты на новом языке.
- `npx tsc --noEmit` и `npm run build` без ошибок.
