# FRONTEND-021: «Почему подозрительно» и «Что проверить» (Premium)

## Контекст
Бэкенд (TASK-094): `GET /api/listings/{id}/risk` (с `X-Telegram-Init-Data`):

```json
{"level": "warning",
 "reasons": [{"code": "prepayment", "title": "Просят предоплату", "explanation": "…"}],
 "checklist": ["Не переводите деньги до просмотра…", "…"],
 "premium_required": false}
```

Без Premium: `title` и `explanation` — `null`, `checklist` пустой, `premium_required: true`.
Тексты уже на языке пользователя — переводить на фронте не нужно.

## Что сделать
1. Страница объявления, рядом со значком «подозрительное» (FRONTEND-012): кнопка
   «Почему?» → раскрывающийся блок:
   - Premium: список причин (название жирным + объяснение) и «Что проверить до встречи»
     (`checklist`, галочками);
   - без Premium: названия причин из своих текстов по кодам (как в значке) и ссылка
     «Подробный разбор и советы — Premium» → `/premium`.
2. У объявлений без подозрений (`level: none`) для Premium — свёрнутый блок
   «Как безопасно снять квартиру» (`checklist`).
3. Вне Telegram (401) блок не показывать.

## Проверка
- Premium видит объяснения и советы на выбранном языке, бесплатный — ссылку на Premium.
- `npx tsc --noEmit` и `npm run build` без ошибок.
