# FRONTEND-053: Без демо-данных — при ошибке сети не показывать выдуманное

## Что не так сейчас
Пока бэкенда не было, «Сохранённые поиски» и «Уведомления» работали на демо-данных.
Бэкенд давно готов (`/api/searches`, `/api/notifications`), а запасной демо-режим остался:
- `hooks/useSavedSearches.ts`: если первый `GET /api/searches` ответил 404 **или не дошёл
  (нет сети, status 0)**, вся сессия переходит в «локальный режим». Человек сохраняет поиск,
  он лежит только в `localStorage`, на сервер не попадает — **уведомлений не будет**, а человек
  думает, что подписался. Плюс показываются выдуманные поиски `mock-1…mock-3`.
- `hooks/useNotificationFeed.ts`: при ошибке — выдуманные уведомления («Однокомнатная квартира
  в Ваке», `mock-n1…`), ссылки на картинки `static/images/placeholders/*.svg`, которых нет.
- `frontend/mock_data.json` и тип `ListingId = string | number` («число — только в mock_data.json»).

Через туннель сеть иногда моргает, так что это не теория.

## Что сделать
1. Убрать демо-режим из `useSavedSearches` и `useNotificationFeed`: данные только с сервера.
   Ошибка загрузки — обычный блок ошибки с «Повторить» (как на других страницах).
   Ошибка при сохранении / удалении поиска — тост с ошибкой, в списке ничего не меняется.
2. Удалить `SEED`-массивы, `localMode` / `shouldFallback`, ключи `localStorage` демо-режима
   (`bina:notifications_read` и т. п.; старые значения у людей просто игнорировать или стереть).
3. Удалить `mock_data.json` и всё, что на него ссылается. Если несложно — `ListingId = string`.
4. По желанию: `saveMockToken` / `clearMockToken` в `lib/session.ts` — это не демо, а отметка
   «вошёл», переименуйте понятнее (`markSignedIn` и т. п.).

## Проверка
- В коде нет `mock-1`, `mock-n1`, `localMode`, `mock_data.json` (`grep -ri mock src`).
- DevTools → Network → Offline → «Сохранённые поиски» и «Уведомления»: ошибка с «Повторить»,
  выдуманных квартир нет. Включили сеть → «Повторить» → настоящие данные.
- Сохранили поиск → он есть после перезагрузки страницы и в другом браузере / на телефоне
  (значит, лежит на сервере, и уведомления по нему придут).
- `npx tsc --noEmit` и `npm run build` без ошибок.
