# TASK-079: Батуми (несколько городов)

## Что сделано (бэкенд)
- **Город у района:** колонка `bina_districts.city` (`tbilisi`, `batumi`), миграция
  `district_city`. Все старые районы — Тбилиси. Районы с одинаковым названием в разных
  городах не смешиваются. Справочник городов — `application/cities.py`.
- **Парсеры:**
  - **ss.ge** — одна выдача на все города; берём города из `SCRAPE_CITIES`. Город
    определяется по `address.cityId` (95 — Тбилиси, 96 — Батуми, проверено на данных
    сайта) или по названию.
  - **myhome.ge** — у каждого города свой адрес поиска. Номер Батуми (`cities=15`)
    проверен через API TNET (TASK-092). Если объявлений Батуми с myhome нет, откройте на myhome.ge аренду
    квартир в Батуми, скопируйте адрес из браузера, замените номер страницы на `{page}`
    и впишите в `.env` → `MYHOME_SEARCH_PATH_BATUMI`. Объявления другого города
    (по `city_name`) отбрасываются.
  - **Telegram-каналы** — каналы тбилисские; пост про Батуми берётся с городом Батуми.
- **Районы Батуми** на ka/ru/en: Старый Батуми, Новый бульвар, Махинджаури, Гонио,
  Кахабери, Чакви, Ангиса, Химшиашвили; незнакомые — транслитерацией.
- **Справка по району и карта:** центры районов Батуми, время до центра считается до
  площади Европы; геокодер ищет адрес в городе объявления.
- **Цены и антифрод** считаются по району, поэтому по городам они уже раздельно.
- **API:**
  - `GET /api/cities` — список городов (код, названия, центр карты);
  - `GET /api/districts?city=batumi` — районы города, у каждого района поле `city`;
  - `GET /api/listings?city=batumi` — объявления города;
  - сохранённые поиски: поле `city` в фильтрах; название по умолчанию «Батуми, 2 комн.».
- **Бот:** в `/search` сначала «🏙 Выберите город» (только если районы есть в нескольких
  городах), затем районы этого города.
- **Договор и акт:** город берётся из объявления («ქ. ბათუმი» / «г. Батуми»).
- **Подсказки ИИ** (перевод, антифрод, помощник) — «Грузия (Тбилиси, Батуми)».

## Настройки (`.env`)
- `SCRAPE_CITIES=tbilisi,batumi` — какие города собирать (пусто — оба).
- `MYHOME_SEARCH_PATH_BATUMI` — адрес поиска Батуми на myhome.ge (пусто — по умолчанию).
